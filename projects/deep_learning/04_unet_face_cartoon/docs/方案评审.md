# 技术路线评审

## 结论

“对齐裁剪 → UNet 人脸解析 → 分区处理 → photo2cartoon → 输出整理”合理可行，能够说明语义分割如何影响生成器输入。不训练或微调，因此不需要下载训练集；如果教师要求训练过程，需另行制定训练任务。

原方案已归档至 [技术路线](技术路线.md)，本次只读参考。项目重点是原理清楚、预后处理有依据，而不是先做复杂界面。

## 核对结果

| 项目 | 官方约定 |
| --- | --- |
| UNet | `feature_scale=4`、19 类，`run_test.sh` 指定 512×512 |
| UNet 输入 | RGB、最近邻 resize、均值和标准差均为 0.5，即 [-1, 1] |
| 类别 | 皮肤 1、鼻子 2、眼镜 3、头发 13、颈部 17、衣服 18，不能套用 BiSeNet 编号 |
| 生成器 | `ResnetGenerator(ngf=32, img_size=256, light=True)`，读取 `genA2B` |
| 生成输入 | 1×3×256×256 RGB float32，[-1, 1]；掩膜不作为第四通道 |
| 裁剪 | 关键点框上扩 0.8 倍高、下扩 0.3 倍高、左右各扩 0.3 倍宽，再补方形 |
| 输出 | 反归一化后 clip，再转 uint8；不默认生成轮廓与输入掩膜重合 |

## 处理原则

- 前景初步保留 1～15，排除颈部、项链、衣服。这是待实测的头像口径，不等同于官方二值分割器。
- 皮肤起点只取 `skin=1`，鼻子单列保护。采用保边滤波、向内衰减权重，软化后仍不得进入五官区域。
- 发色调节默认关闭，保留亮度；不保证生成器准确遵守颜色。
- 关闭区域处理必须恢复完全相同的生成输入；两张漫画共用裁剪、前景和生成器。
- 开关对照只能说明区域处理的影响，不证明 UNet 普遍改善画质。可额外比较“全图平滑／仅皮肤平滑”。
- 每条分支一次生成；四图对照的两张漫画需要两次生成，解析只做一次。
- 默认保留完整白底漫画，不照搬输入细粒度掩膜做生成后编辑，不叠加素描线或强锐化。

## 风险与验收

官方模型偏向亚洲年轻女性，对其他人群、侧脸和眼镜可能表现差；若生成器不合适，替换生成模块而非堆叠滤镜。网盘失效时核对官方来源，不悄悄换模型。无人脸输入应明确失败，不降级为伪漫画滤镜。

顺序：环境与安全加载 → 真实前向 → 对齐与掩膜坐标 → 可关闭的区域处理 → 公开授权人像的四图对照。GPU 合成输入检查不代表真人效果、延迟或显存峰值已合格。
