# 深度学习应用｜CNN 人脸漫画生成技术路线（快速实践版）

日期：2026年10月30日

定位：电脑端核心算法；不训练、不微调；调用预训练模型和现有图像处理方法。

## 1. 方案结论

采用一条四阶段主线：**预处理 → CNN 多尺度结构提取 → 简单漫画渲染 → 合成与展示**。

四种 CNN 是可切换的特征提取器：ResNet50、SE-ResNet50（SENet 家族的具体实例）、EfficientNetV2-S、MobileNetV3-Large。每次运行只使用一种，其他处理方式保持一致。

把此前“多尺度图像结构”和“CNN 特征”合并为一个特征提取模块：多尺度主要来自 CNN 自身的不同层，不再额外维护多尺度高斯、DoG、结构张量等并行管线。只保留一张原图边缘图，用于精确定位；关键点用于五官分组与少量几何约束。内部有必要的数据组合，外部仍是四步接口。

输出目标是**人物仍可辨认、色块简洁、五官清楚、线条较连贯的漫画风格肖像**。第一版不追求夸张变形、特定画师风格、自动去背景或复杂阴影。

这是一套“预训练 CNN 特征引导的程序化漫画化”方案，不是训练好的神经漫画生成器。分类权重不包含从特征还原漫画的能力；任意预训练解码器也不能直接接到四种不同编码器上。后半段因此采用无需训练的渲染方法。CNN 特征是否改善结果仍需实际图片检查，本文给出的是实施方案，未声称已验证效果。

## 2. 四步数据流

| 步骤 | 输入 | 内部处理 | 输出 |
| --- | --- | --- | --- |
| 预处理 `prepare` | RGB 照片 | 方向修正、等比例缩放、轻度去噪、面部关键点、单尺度边缘 | 整理后的照片、坐标变换、辅助信息 |
| 提取 `extract` | 照片＋辅助信息 | 一种 CNN 的多层特征、特征差异归一化、尺度加权、边缘定位约束 | 一张结构支持图＋线条候选分数 |
| 渲染 `stylize` | 照片＋结构信息 | 色彩简化、候选线筛选、路径平滑、可选简单阴影 | 颜色层与笔画层 |
| 展示 `compose` | 图层与配置 | 抗锯齿合成、保存图片与过程面板 | 最终漫画、对照图、运行记录 |

实现上用四个主函数即可，不建设通用工作流引擎。模型加载、文件读写和界面放在外围；函数返回明确结果，避免共享可变全局状态。修改配色时复用 CNN 结果，切换编码器时复用预处理结果。

## 3. 预处理：稳定输入，提供几何辅助

### 3.1 图像整理

1. 修正 EXIF 方向，统一为 RGB；保留原始照片。
2. 第一版使用单人正脸或轻微侧脸，保留完整头发与下巴。允许人工裁剪，暂不增加分割模型。
3. 等比例缩放并填充为 384×384 的工作画布；记录缩放、填充位置。384 是启动尺寸，具体编码器先做输入兼容检查。
4. 仅轻度去噪。明显欠曝时才启用温和亮度校正，不默认局部强对比度增强。
5. CNN 输入按具体预训练权重的颜色范围、均值和标准差归一化；不要照搬分类中心裁剪而截断头发。

工作画布、CNN 输入、关键点与最终显示使用同一坐标基准；输出时撤销填充。OpenCV BGR 与模型 RGB 显式转换。

### 3.2 五官分组

调用 MediaPipe Face Landmarker，按其定义的连接关系选取脸部外轮廓、眼睑、眉毛和嘴部。它提供关键点，不提供完整头发、皮肤和衣服语义分割。

只建立粗粒度五官区域：眼部、眉部、口部，以及脸颊等需要压制碎线的区域。关键点连接用来限定搜索范围、曲线端点和顺序，不把全部面部网格画到最终图上。鼻子先依靠局部边缘，避免机械勾出整个鼻梁。

检测失败时关闭关键点辅助，保留普通漫画化结果并记录状态。侧脸、遮挡、眼镜和强反光要抽样查看，不凭关键点强行补画不可见五官。

### 3.3 单张边缘图

从轻度平滑的原图灰度计算 Sobel 梯度，保存梯度幅值 E 和方向。将有效图像区域的幅值做稳健归一化到 [0,1]。这不是第二套多尺度特征系统，而是给低分辨率 CNN 响应提供像素级定位依据。

**不把边缘图或关键点线条覆盖到 RGB 图上再送给分类预训练 CNN。** 这样会改变其输入分布，也可能让网络主要响应人工描线。也不直接增加第四个输入通道；已有权重通常按三通道图像设计。关键点和边缘在特征之后参与约束，最清晰也最容易调试。

## 4. CNN 多尺度特征：用一张结构支持图承接

### 4.1 编码器适配

| 编码器 | 本次角色 | 备注 |
| --- | --- | --- |
| ResNet50 | 首个跑通的参照编码器 | 先验证整条数据流 |
| SE-ResNet50 | 通道注意力骨干 | 报告写清具体变体，不笼统写 SENet |
| EfficientNetV2-S | 不同结构的多尺度特征 | 不预设其漫画效果更好 |
| MobileNetV3-Large | 轻量候选 | 后续按整条管线耗时决定部署选择 |

使用 timm 的 `features_only` 接口，读取 `feature_info` 获取通道和下采样倍率。优先选接近 stride 4、8、16 的三层；按实际元数据选择，不能对所有模型硬编码同一层索引。四种权重的具体模型标识、版本与预处理配置在实现时查询并固定。全部 `eval`，推理关闭梯度，不训练适配层。

这些层分别提供较细、中等、较粗的空间变化线索。最粗层不是完整场景理解，也不能将某个通道直接解释成“眼睛”或“头发”。第一版不使用分类 logits、类别热图或全局池化向量来画轮廓。

### 4.2 特征变成结构响应

对第 l 层特征 F_l（C_l×H_l×W_l），先按位置做通道向量 L2 归一化：

$$
U_l(p)=\frac{F_l(p)}{\max(\lVert F_l(p)\rVert_2,\varepsilon)}
$$

再计算相邻位置的特征变化：

$$
D_l(p)=\sqrt{\lVert U_l(p+d_x)-U_l(p)\rVert_2^2+\lVert U_l(p+d_y)-U_l(p)\rVert_2^2}
$$

边界使用复制或单边差分。D_l 表示“相邻位置的 CNN 表示变化”，不等于真实边界概率。近零特征需用 ε 防止数值问题；低分辨率结构仍可能偏移。

每层在有效区域内做分位数归一化：

$$
N(D)=\operatorname{clip}\left(\frac{D-q_{10}}{q_{95}-q_{10}+\varepsilon},0,1\right)
$$

近乎恒定的响应直接置零，不能把微小数值噪声拉伸成满幅边缘。双线性上采样到工作画布，得到三张响应 R_1、R_2、R_3。填充区域不参与统计，并抑制填充边缘。

### 4.3 最小融合规则

第一版直接用固定加权和：

$$
S=0.50R_1+0.30R_2+0.20R_3
$$

S 是唯一交给后续的 CNN 结构支持图。三个权重只是便于启动的经验值，并非训练得到或经过验证的最佳设置。较细层权重大，以免粗层响应压过五官细节。无需再增加复杂注意力模块或图结构推理。

CNN 通过 S 控制原图边缘的保留力度：

$$
Q=E\,(0.25+0.75S)
$$

E 提供位置，S 调整该位置的线条支持度，0.25 保留少量 CNN 未覆盖的细线机会。随后在眼睑和嘴缝附近适度降低筛选阈值，在脸颊区域提高阈值。例如分别使用普通阈值的 0.8 倍和 1.3 倍，所有系数只作为启动设置。不要同时再叠加多套加权公式。

这是**启发式门控融合**：CNN 在筛线中实际起作用，但不是独立完成图像生成。若 E 没有检测到某条线，乘法门控也不能恢复它；可靠的眼睑、嘴缝关键点曲线可以作为单独的少量补充笔画，并检查其与图像是否吻合。

先可视化 S、E、Q。如果 Q 明显破坏五官，可减弱门控系数；如果四模型结果几乎相同，应如实报告当前渲染规则更占主导，不人为放大差别。

## 5. “先验＋似然”应该怎样理解

可以用“几何先验与图像证据结合”解释设计，但目前不宜称为严格贝叶斯推断。

| 项目 | 本方案含义 | 是否是概率量 |
| --- | --- | --- |
| 五官顺序、曲线连续、脸颊少描线 | 人工引入的结构偏好，可称几何先验 | 否 |
| 从当前照片估计出的关键点 | 另一个模型提供的几何观测 | 不是独立的先验概率 |
| CNN 特征差异 S | 图像结构的响应分数 | 不是似然 |
| Q 的门控规则 | 综合证据后筛选线条 | 不是后验概率 |

严格贝叶斯形式需要定义待估计结构 Z、观测 I，以及 p(I|Z)、p(Z)，才能写 p(Z|I) ∝ p(I|Z)p(Z)。本次没有建立这些概率模型，也没有校准概率。将关键点与 CNN 分数相乘，并不自动成为贝叶斯融合。

适合汇报的表述是：“利用预训练 CNN 提取多尺度结构响应，并结合人脸几何约束与局部边缘定位，筛选更适合漫画表达的笔画。”这里改善的是整个系统的输出，不意味着改变或提升了冻结 CNN 本身的识别能力。

## 6. 简单渲染：色块＋线条，可选一层阴影

### 6.1 颜色层

用 OpenCV 保边平滑得到 B，再将 B 映射到预设的 8～12 色调色板，形成平涂效果。第一版只准备一个自然暖色板，并保留肤色明暗、发色和衣服的基本颜色覆盖。可在 Lab 空间按色差选最近色，做小范围多数滤波压制零碎色点；不建立复杂区域图。

固定色板只是风格约束，不代表所有人的肤色都应相同。若肤色失真，优先换合适色板或减弱量化；不要凭简单明度阈值推断肤色区域。背景暂时保留并一起简化。

颜色来自照片，CNN 主要负责结构引导；不宣称 RGB 色彩是从 CNN 特征直接解码的。OpenCV 的 `stylization` 可作为快速预览或备用色彩底图，但若使用它，应在报告注明来源，不能把其效果算作四种 CNN 的独立生成能力。

### 6.2 线条层

对 Q 沿 E 的梯度方向做非极大值抑制，再采用高低阈值滞后连接；去掉很短的孤立分量。阈值从非零候选响应的分位数启动，允许通过一个“线条密度”参数调整，不进行正式阈值评估。

将细线转为有序路径：端点与交叉点处分段，闭环单独处理。已有项目的路径追踪代码可作为参考，只复用必要部分，不搬回整套旧管线。对每条路径按弧长重采样，使用 SciPy 参数样条做有限平滑。点数不足时保留折线；眼角、嘴角等急转处保留锚点或分段拟合。

样条允许少量拟合误差，但不允许明显离开原路径。建议工作画布上偏离超过约 1～2 像素就减弱平滑或退回折线；这是起点，不是固定标准。不要把所有线闭合，也不要连接距离远的断口。

第一版只分两档线宽：外轮廓稍粗、内部细节较细；用深棕或深灰替代纯黑。先保证连续和位置正确，再考虑复杂笔锋。关键点曲线只补充少数可靠五官，不绘制面部三角网格。

### 6.3 可选阴影和增强

首版可以没有额外阴影。需要时，从平滑图的低频亮度提取一层软暗部，在粗略脸部区域内轻度压暗；保留色相，避开大范围黑斑。不要将所有局部亮度差都转为阴影。

最终仅温和调节饱和度、整体亮度和对比度。`detailEnhance` 不是必需项，过度细节增强会重新引入皮肤纹理。样条平滑负责笔画形状，图像增强负责视觉观感，两者职责不同。

合成采用笔画覆盖率 A：输出 C = (1-A)B_color + A C_ink。以较大画布绘线后缩回目标尺寸获得抗锯齿效果；这不是超分辨率重建。

## 7. 最小函数接口与记录

```python
# 概念接口，不是可直接运行的完整代码。
prepared = prepare(image, config.preprocess, face_model)
structure = extract(prepared, encoder, config.features)
layers = stylize(prepared, structure, config.style)
result = compose(layers, prepared.transform, config.output)
```

| 返回对象 | 最少字段 |
| --- | --- |
| Prepared | rgb、valid_mask、坐标变换、edge、edge_direction、face_groups、检测状态 |
| Structure | 三层 response、support S、stroke_score Q、模型与层信息 |
| Layers | color、stroke_alpha、可选 shadow |
| Result | final_rgb、阶段图、耗时、配置与提示 |

原始高维特征仅调试时保存，默认及时释放。记录模型标识、权重版本、输入尺寸、库版本、层步幅、配色和参数。不要把结果元数据保存成虚构的置信度。代码与原仓库协作继续遵循“用户本地修改→GitHub→读取”，本技术路线不修改仓库。

## 9. 分阶段实施与完成标准

| 阶段 | 工作 | 达到什么程度即可继续 |
| --- | --- | --- |
| A：单模型 | ResNet50＋自然色板＋简单线条 | 一张照片完整出图，输入输出坐标正确 |
| B：结构引导 | 多层响应融合＋边缘门控 | 能展示 S 与 Q，CNN 切换或关闭确实影响输出 |
| C：五官与曲线 | 关键点分组＋有限样条平滑 | 五官没有明显错位，线条不因拟合而变形 |
| D：四模型 | 同接口接入其余编码器 | 同一批图片可生成四列对照 |
| E：交付 | 三类图与简短说明 | 清楚展示输入、方法、输出及一两个典型问题 |

不增加训练集、微调、人工标注、复杂指标或大规模评估。只用 3～5 张有代表性的自有人像检查：正脸、眼镜、侧脸、较暗光照。查看五官位置、杂线、色块、曲线偏离即可。必要时记录一次预热后的推理及总处理耗时，不能据此保证实时性能。

如果 CNN 响应很粗，不继续增加更多融合分支：优先选更浅层、减弱门控，或承认该骨干对这类渲染帮助有限。如果整体画面不好看，先调整线条密度与色板，不立即引入复杂生成网络。

## 10. 后续应用与 OpenVINO

当前交付只做电脑端单图核心。稳定后再加 `process_frame(frame, previous_state) -> (result, next_state)`，处理关键点平滑和颜色稳定；相邻帧不能简单平均，否则容易重影。

Tauri 2＋React＋TypeScript＋Vite 作为后续应用技术选择，采集与推理解耦，忙碌时丢弃旧帧，只处理最新帧。摄像头授权、设备能力和原生接口另行按平台验证；本次不承诺前端技术栈自动解决手机推理。

OpenVINO 优先尝试加速选定 CNN 的特征输出，导出时保留需要的中间层。图像处理、关键点模型与渲染不会因 CNN 转换就全部加速。先在电脑核对转换前后特征与成图，再测总耗时；移动端模型运行时和打包另设任务。手机访问电脑服务与手机本地推理分别表述。

## 11. 可直接用于汇报的叙事

本项目探索无需训练的人脸漫画化流程。使用预训练 CNN 的不同层提取多尺度结构响应，通过统一融合规则形成结构支持图，再结合原图边缘进行精确定位，并利用人脸关键点约束五官区域。随后采用现有保边平滑、色板映射与样条曲线方法，生成平涂色彩和连续线条。四种 CNN 共享同一渲染流程，比较它们对最终图像的影响。本实验关注流程打通与可解释的图片生成，不将启发式响应视为概率，也不声称得到端到端训练的漫画生成模型。
