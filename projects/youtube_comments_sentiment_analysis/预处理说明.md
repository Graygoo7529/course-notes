# 预处理与统计口径

## 分析单位

CSV 使用 UTF-8 BOM，使用 pandas CSV 解析器读取，不能按逗号或换行手工切分。共有 1,196 行、9 个原始字段，来自同一个视频；`type` 区分 699 条主评论与 497 条回复。

每一行分配 `YT0001` 形式的 `comment_id`。只要原始文件顺序不变，ID 就稳定；运行记录保存原始文件 SHA256。分析单位是记录，不是作者人数。作者及互动字段仅随原始数据保留，不用于建模或加权。没有时间戳或父评论 ID，无法恢复回复树、计算时间趋势或补全对话上下文。

## 文本与语言

| 字段 | 处理方式与用途 |
| --- | --- |
| `text_raw` | 完整原文，不改写，用于回查 |
| `text_clean` | 统一空白、移除零宽空格和 BOM，作为切句输入 |
| `text_model` | 在轻量清理后将提及替换为 `@user`、链接替换为 `http`，用于整体情感 |
| `text_topic` | 移除提及和链接，用于语言筛选、句向量与主题；不做词干化 |

保留否定、标点、emoji 和大小写，避免损坏情感信息。主题的英文停用词处理只作用于 CountVectorizer，不作用于模型情感输入。两组完全重复原文保留，通过 `duplicate_group` 标记；重复记录仍各计一次。

langdetect 固定种子 42。在 `text_topic` 上依次排除空文本、包含汉字、少于三个拉丁词、检测为非英文以及英文分数低于 0.8 的记录。最终纳入 1,082 条，其中主评论 651、回复 431；排除 114 条：空文本 1、汉字或混合语言 35、过短 37、其他语言 28、语言分数不足 13。原文含汉字有 36 条，去除提及后这一数值发生变化。

这些是自动筛选条件，并非真实语言标签；短英文可能被排除。原始行全部保留在结果表，排除原因单独记录，不翻译、不将排除项视为中性。

## 推理与截断

模型均读取自身 `id2label`，不猜测标签顺序。整体情感保留三类概率、最大概率、`p_positive - p_negative`、输入 token 数、截断和状态；最大概率低于 0.6 只作提示，不删除记录，也不等于错误。整体情感上限 512 token，方面文本对上限 256，MiniLM 使用自身 256 上限；实际截断数量见运行记录和报告。

失败明确写作 `failed`，不会填充中性结果。全量主题保留 `-1` 未归类，不强行改派；主题名只用于展示，不更改聚类。二维 UMAP 只用于地图，主题来自五维 UMAP 和 HDBSCAN。

## 方面分析

按最终技术路线，对固定随机 200 条英文记录执行抽样方面分析；不需要人工标签。spaCy 空白英文管线切句并保留句子 ID。BART-MNLI 对六个完整假设独立评分，阈值为 0.60；它不是校准概率或准确率。

若句子含 they／it／these 等指代，而没有规则中列出的明确对象词，则标记 `context_needed`，暂缓方面归属。这是简单启发式，会漏掉或多标对象不明的句子；不尝试补全父评论。所有候选分数与暂缓标记都保留，供回看。

检测到且未暂缓的组合输入 ABSA 文本对接口。先保留句子证据，再按唯一 `comment_id × aspect_id` 聚合：正负并存为混合；正／负与中性并存保留有方向的类别；全中性才是中性；全失败记失败。没有检测到方面的评论仍保留全局结果，不计入方面情感分母。

每张方面横条的分母是该方面被检测到且有有效情感结果的独立评论数；同一评论可跨方面计数，但在同一方面内只计一次。政策情感不自动转换为支持／反对立场，商品 ABSA 模型处理政策和讽刺可能不稳定。

## 最低检查

检查原始行数与合并行数相等、ID 唯一、每条成功情感的三类概率和约为 1、主题总数对应英文记录数、评论—方面唯一且来自固定样本、图表计数与表格一致。不制作准确率、F1、混淆矩阵或人工标注集。
