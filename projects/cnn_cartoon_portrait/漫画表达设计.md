# 漫画表达：从特征到笔画与涂色

> v0.7，2026-10-07。多尺度固定卷积、线条／区域／明暗分支、区域配色、路径追踪与高分辨率绘制已实现并成为默认入口。文中更完整的语义判断、Hessian、流场线描与学习模型仍为后续扩展。具体运行与验证见 [README](README.md) 和 [实施记录](实施记录.md)；[下一版设计](下一版设计.md) 保留 v0.6 的接口记录。

## 1. 先确定画法

本项目暂以“清晰线稿、有限配色、少量阴影的彩色漫画头像”为目标，保留本人五官比例、镜框与发型。漫画并无统一的好看标准：均匀细线、粗细变化、软阴影、平涂都能形成成熟风格。这里选择一种容易解释、比较和用规则实现的画法，不把它视为所有漫画的定义。

一幅清楚的头像应当让重要形状容易辨认，让线条和色块表达同一结构。皮肤可以减少纹理，眼睑和嘴缝却需要清楚；头发可以合成几束，发际线和主要走向仍应保留。清晰度来自这种取舍，也来自边界的准确定位。

学习画法，首先是提炼规则：哪些边界需要描线，哪些差异用色块表达，哪些细节可以省略。当前仍使用单张照片和固定算子；参考画法不意味着训练一个风格转换网络。

## 2. 当前瓶颈

当前颜色分支以保边平滑、软明度映射和细节回填为主。它缓和了第一版突兀的明度分界，但仍输出大量连续色调。颜色减少得不够明确，细节又变软，便容易出现“模糊照片”的观感。直接增加量化强度则可能重新产生脸颊色带，原因是没有先组织阴影形状。

当前线条来自梯度细化和连通筛选，再按响应强弱着墨。响应较弱的镜框或嘴缝可能很淡；强烈的明暗边界却可能获得较重的线。线宽、墨色、笔画连续性尚无独立表达。NMS 约束的是响应位置，不是在模拟笔触。

逐通道特征是合理的基础，但 RGB 在这张照片上高度相关，因此融合响应与灰度路线接近。增加相似通道并不必然增加有效信息。后续需要保留具有不同用途的证据，而不只追求一张更强的总边缘图。

旧遮罩裁掉的头顶与肩部仍需重新标记；渲染不能恢复被排除的人物范围。以下改进应在固定、确认后的遮罩上比较。

## 3. 增加中间表达

下一步采用“卷积特征 → 结构组织 → 漫画绘制”的分工。结构组织层保留区域、曲线、阴影遮罩、置信度与来源；风格层规定调色板、线宽和墨色。更换画法时尽量复用结构。

~~~mermaid
flowchart TD
    A[照片与人物遮罩] --> F[多通道、多尺度卷积特征]
    F --> R[颜色区域与候选边界]
    F --> L[候选细线、走向与连接]
    A --> R
    R --> S[区域内的阴影块与重要细节]
    L --> P[笔画曲线、角色与置信度]
    H[可选少量人工提示] --> R
    H --> P
    S --> C[调色板填色]
    P --> I[线宽、墨色与收尖]
    C --> O[高分辨率绘制与透明合成]
    I --> O
    T[风格配置] --> C
    T --> I
~~~

区域与线条共享证据，但并非同一张图。唇色和肤色之间可以换色而不描黑，嘴缝则可以是一个区域内的独立笔画。因此不要求全部漫画线条闭合，也不依赖这些线条围成所有填色区域。

### 3.1 特征银行

对通道 c 和尺度 σ，保留有符号响应 f_x,c,σ = ∂x Gσ * Ic、f_y,c,σ = ∂y Gσ * Ic。工程上可比较高斯后接 Sobel 与高斯导数两种离散实现，不能在没有标定时直接共用阈值。跨尺度比较导数强度时可使用 σ 归一化，同时记录核截断、像素单位和响应范围；遮罩附近仍需使用前景延拓或归一化处理。

| 特征 | 用途 | 不能直接推断的内容 |
| --- | --- | --- |
| RGB 各通道方向响应 | 保留颜色变化与方向，支持结构融合 | 人物部件名称 |
| 亮度边缘与 Lab 色度差异 | 区分明暗变化和异色交界的证据 | 材质边界与投影的确定分类 |
| 多尺度 DoG／暗脊候选 | 检查细长暗结构、发束与局部纹理 | 自动正确的镜框、嘴缝中心线 |
| 邻域结构矩阵与主方向 | 沿线连接、切向平滑与方向可靠性 | 语义重要性 |
| 人物边界、距离与可选局部提示 | 外轮廓、处理范围、重要小结构保护 | 被原图遮挡或缺失的细节 |

DoG 为 Dσ = Gσ * L − Gkσ * L，k>1。它响应一定尺度的局部变化，符号、尺度和阈值共同决定哪些暗线被选中；单个核并不适应所有宽度。Sobel 对窄暗条两侧都可能响应，因此镜框容易出现双边；应把暗脊候选与梯度边界分别观察，再决定保留中心笔画还是两侧轮廓。

融合应按用途进行。线条分支更关心暗细线和方向，区域分支更关心色差与边界，阴影分支更关心较大尺度明度变化。先保存原始特征，再产生任务各自的融合图，避免过早压缩成单一幅值。

### 3.2 方向与语义

当前 J = Σc ωc vc vcᵀ 只在同一像素汇集通道梯度。当各通道梯度方向相同，J 接近秩一，方向一致性 q 就很高；灰度噪声也可能如此。q 不能当作空间连续性或线条重要性的评分。

可新增 Jρ = Gρ * J，先对三个矩阵分量做邻域汇集，再求主方向，使用与前景一致的边界处理。它增加了邻域方向信息，但会在交叉点、急弯和细线附近混合结构。建议分别保留细尺度响应用于定位、平滑矩阵用于走向与可靠性，不把平滑后的强度直接替换所有细化输入。

卷积给出的是局部证据。眼睑与衣服纹理可能同样细长，皮肤阴影与脸部边界也可能同样强。若坚持不使用预训练模型，可复用交互流程，允许少量“保护此线”“这里同属一个区域”的提示；需要可靠自动语义时，再单独比较人脸关键点或解析模型。

## 4. 线条的绘制

将候选线组织为曲线 γj(s)，另存线宽 wj(s)、墨色 kj、覆盖率 Ej。梯度大小只作为选择证据之一，不直接决定所有线的粗细和深浅。

第一轮可将外轮廓设为较重线，镜框和主要眼睑为中等线，鼻部、下唇与发束内部线较轻。这里的角色需要几何规则或提示支持，不宣称已经自动识别部位。作为参数起点可比较 1 : 0.7 : 0.4 的线宽比例，绝对线宽随输出倍率换算；该比例是实验选择，不是绘画定律。

线条处理顺序为：多尺度候选 → 方向与连通筛选 → 路径追踪 → 有约束的简化／拟合 → 笔画绘制。可将当前 NMS 与连通筛选作为候选基线，先增加路径及着墨表达，再比较 XDoG、沿边缘切向的滤波等候选方法。沿流场采样属于位置相关的定向滤波，通常不能等同于一组处处相同的固定卷积核。

曲线拟合需要限制偏离原图结构的距离，转角、交叉、镜框形状和线端应作为约束。不能仅为平滑而把镜框拐角磨圆，也不能跨越空隙随意连接眼睑与镜框。小连通区域不一定是噪声，瞳孔和嘴角尤其需要保护。

开放笔画可局部收尖，闭合镜框不应强行设置断点。手绘感首先来自线的主次、连续和取舍，随机抖动应放在最后，且未必需要。头发优先表达发块与几条方向线，避免把每根发丝都变成同样黑的线。

渲染时使用独立墨色：Cout = (1−E)Cfill + E Cink，其中 E∈[0,1] 表示笔画覆盖率与透明度的组合。实现应约定色彩空间；优先在线性 RGB 合成后转回 sRGB。这样能独立控制颜色、宽度与透明度。当前 Cfill(1−strength E) 则相当于受限的黑色叠加，不能单独指定墨色。

## 5. 颜色的组织

令 R(p) 为区域编号，S(p) 为区域内的明暗类别，以 P[r,s] 表示调色板颜色，基础填色取 Cfill(p)=P[R(p),S(p)]。抗锯齿只在边界根据覆盖率混合，不要求填色内部都保留照片渐变。

区域编号不必先带“皮肤”“头发”等语义名称。可用颜色与空间邻近生成超像素或初始区域，再依据色差、边界响应和人工提示建立邻接图并合并。聚类可以只拟合当前照片，不需要训练集；但全图颜色聚类缺少空间约束，容易把不同部位合并，不能单独承担结构分割。

每个主要区域先取具有代表性的底色，再指定一个阴影色，必要时加入少量高光。肤色可从原图的合适区域采样并人工调整，保留本人肤色；阴影既改变明度，也允许受控的色相变化。头发可保持较暗的整体，用少量发束亮色表达走向。衣服和嘴唇使用各自配色，避免一套全局量化把它们并入肤色。

阴影需先形成形状，再填颜色。可在区域内对已有基础明度分位数阈值化，结合连通性与边界约束整理成候选阴影块；删除孤立碎片时保护已标记的小特征。基础明度不是真实照明，阈值也不能可靠区分肤色、胡须与阴影。因此先采用保守的一层阴影，必要时允许提示或调整，避免把照相光斑机械地保留成脸部色带。

大面积底色、小面积细节的划分需要结合用途。鼻翼暗线面积很小却重要，皮肤毛孔面积同样小却通常应当舍弃。小细节另存为受保护的遮罩或笔画；暂不全局回填高频细节，防止纹理重新进入已经简化的皮肤。

抗锯齿边界与阴影柔和度也应分开：前者解决采样，宽度通常很窄；后者决定画法，只有选定的过渡区域需要柔化。若将全部边界重新高斯模糊，平涂的清晰感会再次消失。

## 6. 放大与清晰度

双线性或双三次插值可以让小图显示更平顺，但不会恢复已经被平滑抹去的眼睑或嘴缝。锐化提高局部对比，也可能带来噪声和光晕，不能替代结构提取。

更适合本方案的是在原图上确定结构，再在较大画布上重绘。例如从 150×197 的照片提取曲线和区域，将坐标和笔宽统一放大 4 倍，输出 600×788 的漫画。清楚的线条来自显式曲线与笔画覆盖率，而不是把模糊图放大后宣称细节恢复。原图无法确定的形状仍然不确定。

若最终仍需原尺寸，可先在更大的画布上渲染，再面积下采样获得抗锯齿，这属于超采样绘制。区域标签若直接重采样应使用最近邻；若需要光滑轮廓，应从边界几何重新光栅化。RGBA 缩放须在预乘颜色与 alpha 上处理，避免透明边缘串色；计算完成后再按文件约定保存。

转置卷积使用可学习滤波器做上采样，PixelShuffle 将通道信息重排为空间位置。它们都不会凭空产生正确细节；PixelShuffle 本身没有生成新信息的能力，转置卷积也不是普通卷积的逆运算。当前固定算子路线优先采用几何重绘与抗锯齿，未来若引入学习型超分辨率，应单独验证是否改变五官。

## 7. 函数约定

以下为设计层接口。函数接收数组、具名结构和配置，不修改输入；不把“导出图片”混入算法。H、W 为分析尺寸，s 为绘制倍率。v0.7 将 organize_structure 细分为 fuse_line_features、fuse_region_features 和 organize_regions，export_trace 对应 export_comic，其余主要名称保持一致。

| 函数 | 输入 → 输出 | 核心方法 |
| --- | --- | --- |
| extract_feature_bank | RGB I、mask M、配置 → FeatureBank | 多尺度逐通道高斯与方向卷积，亮度／色度、DoG，原始响应与有效域 |
| organize_structure | I、M、FeatureBank、可选提示 → StructureScene | 任务各自的融合；区域邻接与边界、候选线图、置信度与来源 |
| design_strokes | Scene、FeatureBank、笔画配置 → StrokeSet | 路径筛选、受约束拟合、角色、线宽、墨色与收尖 |
| design_fills | I、Scene、配色配置 → FillPlan | 区域底色、阴影遮罩、调色板和受保护的小细节 |
| render_cartoon | StrokeSet、FillPlan、M、倍率 → RGBA | 曲线与区域光栅化、覆盖率、可选超采样、透明合成 |
| export_trace | 具名阶段结果、显示配置、路径 → 诊断文件 | 总览、局部放大、特征图、原始数组、参数与对应关系 |

FeatureBank 的有符号方向响应可按“尺度×通道×方向×H×W”组织，并配套单位、有效域和核参数；StructureScene 保存 H×W 的区域标签和边界证据，以及线图和提示来源。StrokeSet 保存曲线与属性，FillPlan 保存区域、阴影遮罩和颜色表，最终 RGBA 形状为 sH×sW×4。

空间可分离卷积继续服务于高斯、导数核的高效实现；DW 保持各通道独立提取，PW 对选定特征逐点融合。颜色变换、区域合并、曲线拟合和笔画绘制不应统称为卷积。网络结构思想帮助组织特征，完整系统仍是固定算子与图像绘制的组合。

## 8. 观察每一步

保留 v0.6 已有的原始数组和预览，新增的中间结果应直接回答问题：某条线在哪一步消失，某块阴影为何产生，哪个特征阻止了区域合并。优先提供“全图定位＋镜框、眼睑、嘴部局部放大”，并把边界和拟合曲线叠加到原图上。

特征阶段展示 RGB 各通道、不同尺度、亮度／色度、暗脊候选、方向与可靠性。结构阶段展示候选线、保留／删除位置、区域编号和合并前后变化。绘制阶段展示曲线骨架、线宽、墨色、纯底色、阴影遮罩、无纹理填色、最终线稿和合成。

同单位的响应比较采用共同显示尺度；异单位特征分别标注范围，不用各自自动拉满对比度制造改善。有符号量用零点居中的显示，方向图说明模 π 的含义，并隐藏无效方向。区域编号使用固定离散颜色并标注这是标签，不是最终配色。

每个纯函数可以返回 Result 与 Debug，由外层 collect_trace 收集，再由 export_trace 写文件。Debug 应保存必要原始数据和筛选理由，显示映射放在导出层，避免预览图片被误用为计算输入。

先完成三组对照：仅替换线条、仅替换填色、两者合成；再比较直接插值与几何重绘。固定照片、遮罩和显示尺寸，不同时更换多个参数后归因于某一种卷积。可记录线条断裂位置、拟合偏移、区域数量等诊断量，但它们不能替代对人物相似度和画法一致性的人工判断。

## 9. 特征网络与任务融合

### 9.1 网络结构

继续采用不训练的路线时，建议使用全分辨率、多尺度的固定卷积特征网络：输入分成若干尺度，每个尺度先逐通道提取，再经非线性构造与逐点融合，最后输出线条、区域、明暗三组特征。它是按 CNN 连接方式组织的固定算子网络，不具备训练后网络的语义识别能力。

令输入为 I∈R^(H×W×3)，人物有效域为 M∈{0,1}^(H×W)。针对当前小图，可将 σ∈{0.6,1.2,2.4} 原图像素作为实验起点；所有分支 stride=1，输出仍为 H×W。尺度控制观察范围，不能把某个尺度直接命名为“眼睛层”或“人脸层”。更大图片需依据人脸尺寸调整尺度。

每个尺度对 RGB 独立进行高斯平滑，再分别求 x、y 方向响应，得到 H×W×6 的特征；三个尺度合计 H×W×18。高斯可以空间可分离实现，RGB 独立连接对应 DW。固定 Sobel 后接不同高斯与直接离散高斯导数并不完全相同，首轮复用现有 Sobel 实现并记录尺度，避免同时更换所有算子。

RGB 和 Lab 图像还通过旁路保留，后续填色从原始颜色估计。梯度会丢失常量分量，仅靠方向响应无法还原肤色。Lab 转换是逐点非线性变换，不是普通 1×1 线性卷积。

不使用最大池化，避免小图细线进一步丢失定位。多尺度上下文先通过较宽的连续高斯核获取；空洞卷积可以以后比较，但固定稀疏采样可能漏掉细线。残差连接可用于以后可学习网络的优化，当前不会因加入未经训练的残差块就自动得到更高层特征。

### 9.2 提取与融合

对尺度 σ、RGB 通道 c，记 v_c,σ=σ(gx,c,σ,gy,c,σ)^T。σ 因子用于一阶导数的尺度归一化；它不是概率标定，也不会使所有宽度结构具有完全相等的响应。

通道融合仍采用 Jσ=Σc ωc v_c,σ v_c,σᵀ。每通道生成 gx²、gx gy、gy²，非线性后用固定 PW 将 9 个通道汇为 3 个矩阵分量。其最大特征值平方根给出边缘强度 Eσ。对矩阵分量做较轻的空间汇集，Jσ,ρ=Gρ*Jσ，再求法向 θ 与可靠性 q；线条的切向为 θ+π/2。

定位与走向使用不同输出：原始细尺度强度用于细化，邻域汇集后的方向用于连接和平滑。多尺度角度不能直接算术平均，因为它们按 π 周期表示；若要融合方向，可汇集矩阵或使用 cos(2θ)、sin(2θ) 后重新求角度。零响应、角点或交叉处单一主方向可能无定义，应保留有效性标记与原候选。

此外，独立计算 Lab 的亮度梯度和色度梯度，Eab=sqrt(ax²+ay²+bx²+by²)。它揭示颜色变化，不能自动判断材质：阴影、反光、色彩噪声也会改变色度。原生 Lab 单位与归一化 RGB 梯度不同，融合前需要明确尺度 τ，不能直接相加或逐图任意拉满。

暗结构首先观察 Dσ=max(Gkσ*L−Gσ*L,0)，k>1。较宽邻域比中心更亮时产生正响应，能补充梯度对细暗线中心不敏感的问题，但暗斑也会响应。这只是候选；XDoG 的着墨变换与沿流场处理应作为后续独立对照。

若候选仍难以区分细线与斑点，可增加 Hessian Hσ=σ²∇²(Gσ*L)，由三个二阶高斯导数卷积输出 Lxx、Lxy、Lyy。理想暗线横截面呈谷形，法向二阶导数为正、沿线二阶导数接近零；暗点常在两个方向都有较大正曲率。因此可按特征值的符号与比例生成暗脊线索，并用对应特征向量提供方向。实际定位还需法向极值等条件，不能仅靠“一个正特征值”断言是笔画。Hessian 是二阶导数，和一阶梯度外积构成的结构矩阵不是同一种量。

第一轮只增加三尺度梯度、DoG、色度变化与邻域方向，Hessian 留在观察到具体失败后加入。这样可以辨别每类特征是否带来额外信息。

### 9.3 三个输出分支

“融合”可以包含拼接、非线性构造、PW 加权与空间约束，不等于把所有量平均成一张图。建议返回以下具名结构，保留各证据来源。

| 分支 | 特征输出 | 融合意图 |
| --- | --- | --- |
| LineFeatures | edge、dark_ridge_candidate、tangent、orientation_valid、coherence、scale_support、protected | 边界与暗线互补；方向指导连接，尺度支持与提示辅助取舍 |
| RegionFeatures | color_descriptor、right_affinity、down_affinity、boundary、protected | 估计邻接像素是否宜合并；颜色和空间连通共同约束区域 |
| ToneFeatures | region_id、base_lightness、detail_lightness、shadow_candidate、valid | 在区域内部观察明暗，输出可整理的阴影形状 |

线条分支可以先将校准后的细尺度边缘与暗结构响应拼接，经固定 PW 产生候选分数，例如 Sline=clip(we Ê+wd D̂,0,1)。权重为实验配置，分数不是语义概率，单独的 E、D 必须保留，以便决定某条镜框应画暗脊还是两侧边界。q 不应统一乘到全部响应上，否则交叉与转角容易被删除；它更适合决定是否相信方向、是否沿切向连接。跨尺度支持应容许小范围定位偏移，而且不能要求每条细线都在粗尺度出现。

区域分支针对相邻 p、q 构造相似度，例如 a_pq=exp[−(||Δab||²/τc²+η ΔL²/τL²+B_pq²/τb²)]，其中 B_pq 为两点之间的结构阻断证据，η 控制明度差异的影响。它与已实现的 WLS 邻接权重有联系，可复用相关计算，但分区和底色需要独立配置。先形成小区域，再在邻接图上依据颜色、边界和提示合并，不假定线稿已经闭合。仅靠这个公式仍可能把阴影分成不同区域，因此应保留合并层级及人工纠正入口。

明暗分支在区域约束下估计 B，再取 d=L−B。B 可从现有 WLS 扩展，避免跨已确认的区域边界传播；若区域本身过碎，则需先合并再估计，不能直接复用每个像素级小区域。区域编号只表示处理范围，不等于已经恢复物理材质或照明。

### 9.4 驱动绘制

LineFeatures → 线图 → StrokeSet。边缘证据定位边界，暗脊候选定位细暗结构；分别细化和追踪，保留来源，再处理重复与交叉。曲线拟合使用切向作软约束，并保护拐角、线端与标记部位。原始暗线宽度可以作为绘制参考，但最终线宽由画法控制；外轮廓可直接从确认后的 M 取边界。线条角色无法仅凭局部响应可靠自动确定，第一轮允许提示，尚不自动指定“这条就是眼睑”。

RegionFeatures → 区域 R → 底色表 P0。区域融合决定哪里共享一块颜色，区域内部的代表性颜色决定底色。可取去除强暗线和极端亮暗值后的稳健颜色代表值，再映射到指定配色；若样本不足就回退到区域代表值并记录。该颜色仍受照片光照影响，不是真实反射率的恢复。嘴唇、虹膜等小区域可以作为受保护的细节层，不按面积统一删除。

ToneFeatures → 阴影遮罩 Q → 阴影色表 P1。在区域内以阈值 tr 得到候选 Q(p)=1[B(p)<tr]，再整理连通性与边界。阈值可由稳健统计和用户配置确定，但区域明度变化很小时应关闭阴影，不能用分位数强行让每个区域都出现固定比例的暗块。明暗变化明显也未必就是投影，故命名为风格化阴影候选。

填色为 Cfill(p)=(1−Q(p))P0[R(p)]+Q(p)P1[R(p)]。内部先用离散遮罩，渲染时根据边界覆盖率抗锯齿；需要柔和画法时，再独立控制局部阴影过渡。最后在目标尺寸绘制区域与笔画，以 E 为覆盖率、Cink 为墨色，合成 Cout=(1−E)Cfill+E Cink，并按人物边界输出 alpha。不能把 Sobel 或 DoG 图直接缩放后当作已经设计好的漫画线稿。

### 9.5 实际观察

本次使用当前照片和旧遮罩生成了独立观察实验：[六种观察方式](outputs/feature-study-20261007/feature-observation.png)。图中展示原图、RGB 方向边缘、Lab 色度变化、DoG 暗结构候选、已有 WLS 基础明度，以及邻域切向。它们是真实计算或已有中间结果，尚未执行新三分支融合、区域分割或笔画重绘。

RGB 边缘描出了五官周围的变化，DoG 的暗结构候选对镜框、眼睛和嘴缝有响应，同时也保留了碎纹理；色度响应中有额外变化和噪声，不能全部画黑。基础明度仍是连续灰度，后续需要转成有形状的阴影。方向场只表示局部走向，图中的蓝短线不是最终笔画。

观察程序及原始数组保存在 outputs/feature-study-20261007。RGB 三尺度响应乘以 σ 后共用显示上限；不同类别按自身单位显示，上限、截断和方向有效条件记录在 observation.json。保留 observation.npz，避免用显示灰度代替原始数值。该实验复用了旧遮罩，所以不评价人物分割质量，也不以单张照片证明算法泛化。

将来若引入训练数据或预训练权重，可将共享部分扩展为小型 U-Net：编码端获取上下文，跳跃连接保留定位，解码后仍输出线条、区域和明暗三个任务分支。各分支需要对应监督或合理损失，随机初始化的网络和结构本身不会自动提供语义。无论是否学习，都保留原始颜色旁路和中间特征导出。

## 10. 实施顺序

v0.7 已实现本节的第一轮流程。`cartoonize` 返回 ComicResult，保存 FeatureBank、LineFeatures、RegionScene、StrokeSet、FillPlan 和 RenderResult。默认分析尺度 0.6/1.2/2.4，确定性颜色原型 6 个，笔画宽度 0.8 原图像素，外轮廓 1.1，默认绘制倍率 4。区域描述用 WLS，颜色原型只拟合当前照片；按四连通分区，再依据邻接亲和度与色差合并小区域。明度 WLS 禁止跨最终区域连接，平坦区域不强制生成阴影。

笔画使用 DoG 正部与方向细化后的边界候选，强暗线附近抑制重复的双侧边界；连通筛选后做骨架图追踪，分叉处拆分，闭环不收尖。当前拟合是最大偏移受限、保护急弯的折线平滑，尚不是更复杂的样条曲线；笔画角色仅为暗线、边界、外轮廓或人工保护，不自动命名眼睑等语义。保护／删除提示以原尺寸二值 PNG 提供。

区域边界在细化网格上提取并以多边形重绘；近邻标签作覆盖底图，防止简化边界产生空洞。填色与笔画在目标画布合成，透明轮廓使用距离场覆盖率；额外超采样时在线性 RGB 与预乘 alpha 上下采样。原图缺失结构、旧遮罩裁切与半透明发丝仍不能由该绘制步骤恢复。

第一步扩展并展示特征，围绕镜框、眼睑、嘴缝检查细线候选，再加入独立墨色、线宽与曲线重绘；先证明线稿有所改善。第二步加入区域配色，先完成底色与一层阴影，比较是否仍像模糊照片。第三步整理区域与曲线约束，在更大画布上渲染；最后再考虑流场线描、发束、局部渐变或画笔纹理。

这里最困难的是从照片中可靠选出“应画的结构”，尤其是小图的五官。应把自动候选与人工提示并存作为可行起点；先获得可以解释的结果，再逐步提高自动化程度。
