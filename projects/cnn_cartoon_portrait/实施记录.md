# 实施记录

## 2026-10-06：最小管道

本轮完成设计 v0.2 的七个函数，并提供命令行入口、可选的矩形与笔划标记窗口，以及中间结果导出。代码位于 `src/cartoon_portrait`：`pipeline.py` 保存核心运算，`selection.py` 收集标记，`cli.py` 串联步骤，`artifacts.py` 管理结果文件与合成图。

接口使用 float32 RGB/RGBA、bool 遮罩和统一的原图坐标。GrabCut 可由矩形或四类标签初始化；提供 `--mask` 时直接复用已确认的二值遮罩。核心处理函数不修改输入，也不打开窗口或读写文件。

### 实现约定

高斯核半径为 $r=\lceil3\sigma\rceil$，核宽 $2r+1$；$\sigma=0$ 时仅保留前景颜色。横纵一维卷积使用反射边界，分子、分母都完成两个方向的卷积后再相除。遮罩外输出为零，不具有前景颜色含义。

描线前使用 OpenCV 的距离标签，将邻近前景灰度延拓到背景；该距离计算采用 $5\times5$ 近似。之后以 $3\times3$ Sobel 核除以 8 计算两个方向，单位阶跃的峰值响应为 0.5。延拓只用于避免占位零值造成假边缘，不会改变人物遮罩，也不恢复发丝颜色。人物外轮廓由 alpha 保留，本版没有额外沿遮罩描黑边。

颜色量化仅作用于 Lab 明度，默认 6 档、混合强度 0.65。量化和提线是两个独立分支。最终 RGB 为 $C(1-\lambda E)$，alpha 为二值遮罩；PNG 保存非预乘 RGBA，浅深背景预览只合成一次。

### 验证结果

使用 `d2l` 的 Python 3.13.14，项目内依赖为 NumPy 2.5.3、OpenCV 4.14.0.94、Pillow 12.3.0，类型检查使用 ty 0.0.84。

`python -m unittest discover -s tests -v` 的 14 项检查全部通过，`python -m ty check` 通过。主要检查了卷积的常量保持与背景隔离、Sobel 响应尺度、量化范围和输入不变性、空遮罩与非法参数、EXIF 方向、中文路径、透明度保存、标签和遮罩复用，以及已有结果不被覆盖。

通过 `python run.py --demo --output outputs/synthetic-baseline` 跑通整条管道。合成图尺寸为 $480\times560$，人物肩部接触画面底边；GrabCut 遮罩与已知前景的 IoU 为 1.0000。该图背景和人物颜色刻意分离，**此数值只验证这张合成图，不代表真实自拍的分割能力**。

已检查生成的六步总览：背景删除、平滑、明度分层、五官描线与最终合成均可观察。图中的头发和衣服也出现了量化边界，说明固定档数可能产生不够自然的色阶；后续应在自拍上判断是否需要减弱量化。

## 2026-10-07：首张照片结果分析

分析对象为 `outputs/20261006-231358-781351`，输入尺寸 $150\times197$，采用全部默认漫画参数。背景已大体移除，RGBA 的 alpha 仅含 0 和 255，且与保存的遮罩完全一致；主要问题依次是保留范围、平滑尺度与明度量化。

初始化标签只包含确定背景 0 和可能前景 3，没有前景/背景笔划。前景候选恰为矩形 $x=24\ldots124,\ y=22\ldots156$（坐标含端点）。矩形顶部穿过头发，底部止于颈部，因此框外的头发和肩部不可能被后续 GrabCut 或漫画化恢复。下一次框选应覆盖期望保留的完整人物区域；若只需要头像，也应完整保留头顶并另行确定自然的裁切位置。

默认 $\sigma=1.5$ 对应 $11\times11$ 高斯核。在这张低分辨率照片上，平滑图中的镜框、眼睛和嘴部已经明显变模糊。明度 6 档、混合强度 0.65 随后将原本渐变的光照变成额头斜向分界和脸颊局部亮斑；这些色块在叠加线条之前就已出现。

在同一遮罩下，分别只将 sigma 调到 0.6、只将 amount 调到 0.3、只将 strength 调到 0.5，并额外生成三项一起调整的结果。对照保存在 `outputs/20261006-231358-781351-analysis`，每幅图仅为显示而最近邻放大 3 倍。

减弱平滑能保留更多镜框细节，也会使原来的 Sobel 参数画出更多杂线；减弱量化可缓和明暗分界，但无法恢复已经模糊的五官；只减弱描线不能消除色阶斑块。三项合调的结果可作为下一轮起点，仍不视为最佳漫画效果。

下一轮优先放大小图标记预览、修正人物范围，再调整小图的平滑尺度与风格强度。进一步的方法替换应先比较保边平滑，并继续区分人物轮廓、五官结构与光照渐变。原始结果和处理代码在本轮分析中保持原样。
