# 从边缘响应到漫画笔画

本轮检查 v0.7 的实际自拍结果，补充可复用的观察工具，并据此设计后续实验。基准为 `outputs/comic-v07-selfie-final`：输入 150×197，输出 600×788，沿用之前的人物遮罩。观察结果位于 [特征观察室](outputs/comic-v07-selfie-final-inspection/index.html)，含 145 张特征或阶段 PNG、原始状态、数值计算与回放动画。

本轮落地的是诊断工具和计算过程的显式记录；下文的流场滤波、断点连接与曲线笔压仍是待验证设计。当前线条计算经重构后，与存档的候选、分数、筛选结果及骨架逐像素一致。

## 1. 先明确画法

本项目可以先以清晰线稿、平整底色和少量阴影组成的彩色漫画肖像为目标。评价时，首先看五官与人物是否仍可辨认，再看线条和色块是否有组织。更多边缘、更少颜色、更粗黑线，都不能单独定义好的漫画。

对于这类画法，镜框需要稳定地交代形状；上眼睑、嘴缝需要简洁而准确；鼻梁、下眼睑和皮肤起伏可以有意省略。线条的断开应当服务于光照、遮挡或省略，而不是由随机阈值造成缺口。发丝也不必逐根描出，可以用少数方向一致的发束和整块暗色共同表达。

线宽应当有主次，例如较明确的外轮廓配合较轻的面部细节，并随一整笔平稳变化。刻意抖动每个像素、统一加粗所有边缘，都会放大现有碎裂。实际手绘教程也将连续落笔、线重与深度表达分别讨论，提醒不要把每一条线都加粗。这是一种可借鉴的画法，并非所有漫画的共同规则。[shiraishiku：Lineart](https://tips.clip-studio.com/en-us/articles/3800)

底色与阴影则各有职责：底色帮助辨认皮肤、头发、衣服等外观；阴影概括体积与光照。如果肤色随着照片每一点明暗变化分成许多不同底色，即使色块内部很平，也仍容易像照片的硬量化。

## 2. 当前证据

这次结果已经摆脱上一轮整体柔化的观感，镜框、嘴缝与大块颜色比较明确。但发际线、眉眼附近存在碎段，鼻部有零散短线，部分色块边界呈锯齿或折线。头顶和脖子的平切来自复用的旧遮罩，不能用它评价线条算法的完整人物轮廓能力。

对全图内部骨架和实际筛选规则进行统计：

| 项目 | 结果 | 含义 |
| --- | --- | --- |
| 骨架连通部分 | 59 | 在曲线拟合之前，已经存在很多互不连通的部分 |
| 图追踪产生的路径 | 94 | 一处真实分叉也可能拆成多条路径，不等于 94 个连通部分 |
| 保留的内部路径 | 70 | 另有 1 条外轮廓，合计存档中的 71 条 |
| 保留路径短于 5 原图像素 | 35 | 一半路径很短；不能直接认定它们都是噪声 |
| 保留路径长度中位数 | 约 4.91 原图像素 | 长度按当前筛选代码中相邻采样点的距离和统计，拟合前计算 |
| 正常骨架细化移除 | 89 像素 | 响应带变窄时的正常去除 |
| 骨架中未被任何保留路径覆盖 | 32 像素 | 与上一项含义不同，应分别观察 |

此前 `lines_rejected.png` 实际是 `retained & ~accepted`，其中混合了最后两项。看到这张图上有眼部响应，并不能直接断言这些结构全被当作噪声删掉。新版观察器分别输出 `thinning_removed` 和 `path_removed`，两者互斥，合并后恰好还原旧图。

最细尺度的 RGB 幅值相关系数为 R/G≈0.963、R/B≈0.929、G/B≈0.977。融合结构强度与加权 RGB 灰度梯度幅值的相关系数约为 0.998，统计范围是整个前景。这表明本图大部分强变化在不同颜色通道中共同出现；局部色差仍有用，但只调整 RGB 权重，预计不足以补出完整的眼睑和发束。相关性不是质量指标，也不能推论其他照片中的颜色边界不重要。

### 断裂发生在哪里

当前线条链为：最细尺度边界与 DoG 正部 → 幅值截断 → 方向细化 → 暗线邻域抑制 → 取最大值融合 → 连通筛选 → 骨架 → 图路径 → 有限折线平滑 → 着墨。

**第一处需要对照的是截断顺序。** NMS 要比较峰值，但 `clip(E,0,1)` 会把不同高度压成平台。例如一行响应为 `[0.2, 0.6, 1.4, 1.6, 1.2, 0.6]`，截断后中间三个数都变成 1。沿水平方向细化时，一侧严格比较可能选中平台左端，而不是原先的峰值。当前自拍中，仅将顺序改为“未截断幅值先 NMS，再截断”，边界图有 69 个像素变化，暗线图有 29 个像素变化。观察器保存了差值，但尚未将这些候选送入最终绘制，也不能把全部变化视为改善。

**第二处是不同候选之间的硬抑制。** 代码将强暗线周围 3×3 邻域的边界候选直接清零，目的是避免同一细暗线被描成双边。实际有 657 个非零边界候选因此消失，其中 534 个在乘以边界融合系数 0.65 后原本达到低阈值。不过，它们可能是重复边，也可能来自邻近眼睑；数量本身无法判定误删。当前规则尚不比较方向、位置和线宽，不能确认被抑制的两种证据指向同一个结构。

**第三处是多尺度与方向没有充分用于组织线条。** 三个尺度都已提取，但暗线只使用 `dog[0]`，细化只使用 `theta[0]` 和 `coherence[0]`。跨尺度最大强度只产生 0.75–1 的乘数，调整已有候选幅值，不能跨过零响应连接缺口。图追踪函数只读取二值骨架，没有读取方向场；它在分叉处拆分路径，也没有处理相邻断点。

**第四处是笔画设计仍然局部。** 当前拟合只平滑已经存在的折线，并限制点的偏移，端点不动；它不会把不同路径连成一笔。内部暗线与边界主要使用两档线宽，短线的开放端还会收尖。对许多本来就很短的片段反复收尖，会让画面更显零碎。应先整理完整路径，再决定哪些端点是真正的落笔、收笔位置。

## 3. 卷积的实际分工

以下分类对应笔记中的“连接哪些通道”“空间核能否分解”“怎样采样”等不同维度。同一算子可以同时属于几类。

| 当前方法 | 与卷积的关系 | 输出与用途 |
| --- | --- | --- |
| RGB 高斯平滑 | RGB 各自处理是 DW；高斯横纵分解是空间可分离 | 三通道轻度去噪引导图 |
| Sobel／可选 Scharr | 固定方向互相关；每通道两个方向，相当于 DW 的倍增系数 M=2；每个核也可空间分解 | 六张有符号方向图，以及三张非线性幅值图 |
| `gx², gx·gy, gy²` | 逐点非线性乘积，不是卷积 | 每通道三项，共九个结构特征 |
| RGB 二次项加权 | 固定 1×1 PW，九项按类别合成三项 | Jxx、Jxy、Jyy；进一步计算结构强度 |
| 结构张量空间平滑 | 对三个张量分量分别做高斯；DW 与空间可分离 | 更稳定的法向及方向一致性 q |
| 多尺度 DoG | 两路高斯卷积作差，之后取正部才引入非线性 | 局部暗结构候选；并不严格等同于暗脊中心 |
| Lab 色度梯度 | Lab 转换是逐点非线性；a*、b* 上的 Sobel 是逐通道方向滤波 | 色度变化图，目前主要用于观察 |
| WLS、聚类、NMS、连通筛选、骨架与路径 | 不是普通固定卷积 | 整理区域、筛选候选与建立绘制几何 |
| 邻域最大值、形态学膨胀 | 非线性形态学操作，**不是空洞卷积** | 暗线附近的抑制范围 |
| 插值、标签重绘、覆盖率抗锯齿 | 采样与绘制，不是已训练的上采样卷积 | 更细画布上的轮廓与颜色覆盖 |

以逐通道结构为例，令 v_c=(gx,c, gy,c)ᵀ，则 J=Σc ωc v_c v_cᵀ。每个外积中的平方与乘积先生成非线性特征，随后按通道加权才是 PW。这样相反符号的梯度不会直接抵消，但整个流程已经不能合并成一个线性 DW+PW 核。因此，它借用了深度可分离卷积的空间／通道分工，不能称为一个训练好的 MobileNet 模块。

Sobel 的 Kx=[1,2,1]ᵀ[-1,0,1]/8，分别表示纵向平滑与横向差分。能拆成横纵两步不意味着一定用于平滑：分解是计算结构，去噪或求导是核的用途。这也解释了为什么“再使用一种空间可分离卷积”不是足够具体的改进目标。

还需注意遮罩归一化：实际引导图为 G*(MI)/(G*M)。其中的高斯分子和分母可分离；加上位置相关的归一化后，整体不再是平移不变的普通卷积。DoG 则是两个可分离高斯之差，一般不能再视为单个秩一的二维核。

## 4. 让特征围绕任务组织

### 提取不同证据

后续共享特征可以保留三类互补信息：一阶导数寻找区域边界，DoG 或二阶导数寻找窄暗结构，多尺度方向与邻域一致性描述它们的走向。旋转更多 Sobel 方向通常只是组合现有 gx、gy，未必增加新的结构信息。

对平滑后的明度 Lσ，可进一步计算 Hessian：Hσ=[[Lxx,Lxy],[Lxy,Lyy]]。若某个位置沿法向明显向上弯曲，而沿切向变化较小，即对应法向特征值为正且绝对值较大、切向特征值较小，就更接近窄暗线中心。二阶导数可由高斯导数核获得，并用 σ² 作尺度归一化，再比较局部噪声与尺度响应。这个设计比仅看梯度更直接地针对“暗线中间”，但也会响应暗斑、压缩噪声，仍需筛选。

多尺度特征不应全部取最大值后丢弃来源。线条分支应保留候选类型、尺度、中心位置、法向、置信线索和估计宽度。例如细尺度保护眼睑与嘴缝，较粗尺度稳定镜框或发束；相邻尺度一致可以增加支持，但不能强制每一条细线在粗尺度也出现。

区域分支关注“相邻两点是否应同色”，应结合色差与结构阻断；明暗分支关注区域内较缓慢的亮暗变化，保留基础层与细节层。两者不能直接套用线条分数：重要的黑色笔画未必是底色边界，底色边界也未必应该描黑。

### 沿走向汇集

令 n(p) 为局部法向，t(p) 为垂直于它的切向。一个直接针对连续性的设计是：先沿法向检测线条，再沿切向的流线整合响应。若流线满足 γ′(s)=t(γ(s))，可写成 D̃(p)=Σs w(s)D(γ(s))/Σs w(s)。弯曲流线上的非整数坐标用双线性插值读取。

直观上，这是沿一条眼睑或镜框的走向积累证据，同时限制跨线扩散。它与把所有方向一起高斯模糊不同。ETF／FDoG 文献正是围绕方向场和沿流线滤波来改善线描连贯性；文献也指出，沿线范围过大可能引入错误结构，方向估计与滤波尺度需要配合。[XDoG，§2.6](https://www.kyprianidis.com/p/cag2012/winnemoeller-cag2012.pdf)

流线追踪时 t 与 −t 表示同一个走向，不能直接把有正负翻转的向量平均。可继续平滑结构张量，或先对邻近切向做符号对齐；还要在方向不可靠、转弯过急或遇到强横向边界时停止。尤其不能将靠近镜框的眼睑抹到镜框上。

这属于方向引导、采样位置随图像变化的滤波；不能直接归类为固定坐标轴上的空间可分离卷积。它与可变形卷积“调整读取位置”的思想有联系，但本设计用规则构造流线，没有学习偏移，也没有实现 DCN 网络。

### 再组织成笔画

路径连接应同时考虑断点距离、两端切向、预测曲率、缺口中的弱响应，以及保护／删除提示。第一轮可以只测试 1–3 原图像素的短缺口，但距离短并不充分：眼睑和镜框也可能只有这个间距。无法判断的连接应保留不确定性，允许少量提示。

分叉处则需要判断哪些边更像同一笔的延续。当前按图节点机械拆分的做法容易产生很多短支路；下一轮可以比较进入与离开方向，在保留真实分支的同时形成较长笔画。不能为了减少连通分量而把所有线都连起来，也不能用长度阈值统一删除眼角等重要短线。

连接之后再做曲线拟合，约束位置误差、端点和必要拐角；可比较当前折线与分段 Bézier。线宽沿弧长平滑变化，收尖只作用于真实开放端，闭合镜框不收尖。笔压、墨色与线宽层次独立于检测强度：照片中对比度弱的眼睑，也可以被设计成明确的一笔。角色判断仍需要上下文或提示，不能把“梯度强”直接等同于“应画粗”。

### 配合色块

当前区域是颜色聚类和连通整理的结果，没有自动识别皮肤、嘴唇或头发。下一轮应检查同一外观是否被光照分成多个底色区域，再考虑共享底色，把主要明暗变化留给独立阴影层。嘴唇、虹膜等小范围细节需要保护，不能与皮肤中的碎噪声使用同一面积规则。

优先让色块边界与笔画结构协调，再调整指定配色与局部柔和过渡。高分辨率绘制可以减少阶梯感，但放大不会恢复原图没有捕获到的眼睛结构；当前已经有 4 倍重绘，主要短板仍在绘制前的几何与选择。没有训练或明确高分辨率特征来源时，转置卷积和 PixelShuffle 也不能自行补出这些信息。

## 5. 建议的函数链

下面是下一轮设计接口，尚未实现的函数不表示已有能力。

| 函数 | 输入 → 输出 | 方法与目标 |
| --- | --- | --- |
| `extract_evidence` | 照片、遮罩 → 多尺度特征库 | 逐通道高斯、一阶／二阶方向卷积；保留原始响应与通道来源 |
| `estimate_line_flow` | 结构张量、强度 → 切向场与有效范围 | 张量空间平滑或 ETF 式方向整理；避免弱噪声中的虚假方向 |
| `fuse_task_features` | 特征库、流场 → 线条／区域／明暗描述 | 非线性特征后 PW 汇总，按任务使用不同证据；保留尺度与来源 |
| `filter_along_flow` | 暗线或边界响应、流场 → 连贯候选 | 法向检测与切向积分、双线性采样、可靠性和曲率限制 |
| `trace_and_join` | 候选、切向、提示 → 路径图与连接理由 | 连通筛选、断点匹配、分叉延续；记录拒绝原因 |
| `design_strokes` | 路径、角色提示 → 曲线与笔画属性 | 约束拟合、平滑线宽、真实端点收尖，避免对碎段逐一装饰 |
| `plan_fills` | 区域／明暗描述、配色 → 底色与阴影 | 稳健取色、区域合并、受保护小细节、明暗层分离 |
| `render` | 笔画、填色、遮罩 → RGBA | 目标画布重绘、覆盖率抗锯齿与正确 alpha 合成 |

实施时先固定照片、遮罩和其余参数，比较 NMS 顺序及重复边界抑制；然后单独加入沿线滤波，再加入路径连接，最后调整线宽与配色。每轮都看镜框、眼睑、嘴缝是否改善，以及是否出现误接、位移或细节损失，不用“线更多”或“分量更少”替代效果评价。以后若引入预训练或监督学习，可用保留高分辨率分支／跳跃连接的网络预测线条、方向、宽度和区域，但要解决权重与监督来源问题。

## 6. 观察工具

新增入口 `inspect_run.py` 从已有 v0.7 结果读取存档，使用与正式管道共用的 `trace_line_features` 重放关键阶段，并检查与原数组的最大差；不一致时拒绝生成解释。高斯横纵分解从保存的 8 位输入重算，单独记录与存档引导图的误差，避免把可能存在的颜色量化误差藏起来。本次自拍两项误差均为零。

~~~powershell
conda activate d2l
python inspect_run.py --run outputs/comic-v07-selfie-final
~~~

默认新建 `comic-v07-selfie-final-inspection`，已存在时拒绝覆盖；用 `--output` 可另起一次观察。输出内容包括：

- `index.html` 与 `trace-data.js`：离线观察页。切换分支、通道和尺度；点击图像或输入坐标，查看 3×3 乘加、九项结构特征的通道贡献、J、特征值与方向；支持滑动窗口、阶段播放和暂停。
- `maps/`：完整尺寸的 PNG。方向响应及 xy 交叉项保留正负，不取绝对值掩盖差异；同类特征共用显示上限。页面显示增益只调对比度，不修改数组。
- `trace.npz`：全图高斯分解、逐通道二次项、融合前后张量、线条阶段和 NMS 顺序对照。原始 gx、gy 等仍在来源目录 `features.npz`，manifest 记录其位置与散列。
- `manifest.json`、`statistics.json`：参数、数据来源、量程、窗口坐标、数组轴约定和路径统计。
- `line-stages.gif`：实际照片与真实阶段图的回放。它展示原有线条如何产生，不是新风格的效果预告。

数值交互窗口最大为 256×256，较大图片默认围绕前景中部选取窗口，不缩放数值；全图 PNG 与 NPZ 仍完整保存。可用 `--crop X Y W H` 选择需要检查的局部。对当前 150×197 自拍，数值窗口就是全图。观察器面向离线分析，保存详细数组与图像会增加磁盘占用，因此暂不默认附加在每次普通转换中。

本轮观察以逐通道卷积、张量融合和线条去留为重点。颜色分支已显示邻接亲和度、基础／细节明度及阴影筛选；WLS 每次迭代、每一次区域合并和沿流线采样动画尚未实现，可在对应算法进入下一轮实验时继续增加。
