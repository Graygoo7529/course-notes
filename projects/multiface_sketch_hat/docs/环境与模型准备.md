## 4. 下载三个权重

| 模型 | 用途 | 本地位置 |
| --- | --- | --- |
| YOLOv5s-Face | 必需，人脸框 + 五点 | `model/yolov5_face/yolov5s-face.pt` |

为按路线选型，本次准备两种生成器；应用运行时最终只需加载选定的一种。

```powershell
New-Item -ItemType Directory -Force model/yolov5_face, model/informative_drawings, model/u2net_portrait | Out-Null

# 这些 ID 来自官方仓库；使用 ID 可兼容 gdown 5 的链接解析。
python -m gdown 1zxaHeLDyID9YU4-hqK7KNepXIwbTkRIO -O model/yolov5_face/yolov5s-face.pt
if ($LASTEXITCODE -ne 0) { throw 'YOLO5Face download failed' }

python -m gdown 1MIdHzecxz-z0uY3ARL_R40DlKcuQxiDk -O model/informative_drawings/model.zip
if ($LASTEXITCODE -ne 0) { throw 'Informative Drawings download failed' }
python -m zipfile -t model/informative_drawings/model.zip
if ($LASTEXITCODE -ne 0) { throw 'Invalid model.zip' }
python -m zipfile -e model/informative_drawings/model.zip model/informative_drawings
if ($LASTEXITCODE -ne 0) { throw 'Model extraction failed' }

python -m gdown 1IG3HdpcRiDoWNookbncQjeaPN28t90yW -O model/u2net_portrait/u2net_portrait.pth
if ($LASTEXITCODE -ne 0) { throw 'U2Net Portrait download failed' }

Get-ChildItem model/informative_drawings -Recurse -Filter netG_A_latest.pth
python scripts/check_environment.py --require-models --output .cache/environment-and-models.json
```

保留压缩包内的风格目录，不将多个 `netG_A_latest.pth` 平铺覆盖。当前主风格是 `model/anime_style/netG_A_latest.pth`，对应 Lineart fine；`opensketch_style` 和 `contour_style` 作为后续对照。检查脚本只记录文件是否存在、大小、SHA-256 以及可疑 HTML，不反序列化模型；哈希是本地记录，不冒充官方公布的校验值。

官方来源与手工下载入口：

- [YOLO5Face 权重表](https://github.com/deepcam-cn/yolov5-face#pretrained-models)：[Google Drive](https://drive.google.com/file/d/1zxaHeLDyID9YU4-hqK7KNepXIwbTkRIO/view)，[百度网盘](https://pan.baidu.com/s/1fyzLxZYx7Ja1_PCIWRhxbw)，提取码 `eq0q`。
- [Informative Drawings](https://github.com/carolineec/informative-drawings#testing)：[model.zip](https://drive.google.com/file/d/1MIdHzecxz-z0uY3ARL_R40DlKcuQxiDk/view)。此处不是训练用的 feats2depth.zip。
- [U²-Net 官方说明](https://github.com/xuebinqin/U-2-Net)：[人像权重](https://drive.google.com/file/d/1IG3HdpcRiDoWNookbncQjeaPN28t90yW/view)，[百度网盘](https://pan.baidu.com/s/1BYT5Ts6BxwpB8_l2sAyCkw)，提取码 `chgd`。不要换成背景分割的 `u2net.pth` 或 `u2netp.pth`。

Drive 配额或网络导致 gdown 失败时，用官方页面手动下载到同一路径。不要把网页保存成 `.pt`。若是代理证书错误，可对这次 gdown 命令追加 `--no-check-certificate`，无需全局关闭 SSL；这不解决配额或权限错误。[gdown 用法](https://github.com/wkentaro/gdown)

## 6. 可选：在 d2l 启用 GPU

当前 `+cpu` torch 不能通过改 `device='cuda'` 解决。需要成对更换 torch/torchvision 的 CUDA wheel。为适配现有 536.45 驱动，提供 PyTorch 2.7.1 + torchvision 0.22.1 + CUDA 11.8 的保守候选组合；官方索引确有 Python 3.13 / Windows wheel。此组合尚未在本机安装或验证完整项目，不称为已验证环境。

这一步会更换 d2l 中两个核心包，建议先克隆环境作为回退：

```powershell
conda create -n d2l_before_sketch_gpu --clone d2l
if ($LASTEXITCODE -ne 0) { throw 'Environment backup failed' }
conda activate d2l

python -m pip install torch==2.7.1 torchvision==0.22.1 --index-url https://download.pytorch.org/whl/cu118
if ($LASTEXITCODE -ne 0) { throw 'CUDA wheel installation failed' }
python -m pip check
python scripts/check_environment.py --output .cache/environment-gpu.json
```

检查报告应出现 `cuda_available: true`、正确 GPU 名称、成功的卷积与 NMS 结果，且没有 `runtime.error`；模型整体性能仍待下一阶段测试。若已有其他包严格绑定当前 torch，先根据 `pip check` 解决或使用环境副本，不忽略冲突。只做预编译模型推理时不要求另装系统 CUDA Toolkit。复用现有旧驱动不等于对所有更高 CUDA wheel 都兼容。

依据：[PyTorch 对应版本安装指令](https://pytorch.org/get-started/previous-versions/)、[cu118 torch wheel](https://download.pytorch.org/whl/cu118/torch/)、[cu118 torchvision wheel](https://download.pytorch.org/whl/cu118/torchvision/)、[NVIDIA 驱动兼容说明](https://docs.nvidia.com/deploy/cuda-compatibility/minor-version-compatibility.html)。
