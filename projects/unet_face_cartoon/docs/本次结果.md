## 观察

| 样例 | 观察结果 | 尚存问题 |
| --- | --- | --- |
| 刘亦菲 | 可获得五官与发型较清楚的漫画；可选发色对输出发色有可见影响 | 发顶接触边界，围巾中与头像连通的误分部分仍有残留 |
| Eileen Collins | 头发、面部、笑容均生成；去除了肩章被误判成帽子的孤立块 | 明显年轻化、肤色变淡，不能声称保持原貌 |
| Barack Obama | 单人检测、解析与生成成功，主要表情可观察 | 肤色被明显淡化、五官变化，反映生成器覆盖与偏差问题 |

第一轮可见的孤立块促使实现增加“保留主要皮肤所在前景连通域”的规则。最终默认运行分别清理 3331、1623、0 个前景像素；不修改原始标签，也不按面积删除眼睛、嘴唇。不同 GPU 运算批次可能出现极少量边界像素差异，因此数值是这一次运行记录，不承诺跨运行逐比特一致。

剩余的连通误分没有用手工定点涂抹掩盖。后续可以研究更可靠的前景模型或生成器，但应先保留当前失败样例作比较，不用不断叠加滤镜代替问题诊断。

## 开关影响

以 0～255 RGB 值的平均绝对差记录开关影响，**这不是质量指标**：

| 样例／参数 | 生成输入差异 MAE | 漫画输出差异 MAE |
| --- | ---: | ---: |
| 刘亦菲，皮肤 0.5 | 0.111 | 0.135 |
| Eileen Collins，皮肤 0.5 | 0.107 | 0.213 |
| Barack Obama，皮肤 0.5 | 0.144 | 0.264 |
| 刘亦菲，皮肤 0.5 + 发色 0.35 | 2.267 | 2.081 |
| 刘亦菲，所有区域控制关闭 | 0 | 0 |

这些清晰照片上的轻度皮肤简化视觉差异很小，是正常的实测结果；不能为了展示而称其显著提高质量。发色改变更容易观察，但输出颜色并不等于指定的输入目标色，变化也不严格局限在输出头发区域。

最终默认运行含图像保存的逐图耗时约 19.5、3.2、2.4 秒；第一张包含首次算子/JIT 等开销，模型初始化另计。这不是独立基准测试，未系统测峰值显存、冷启动或 CPU 速度。
