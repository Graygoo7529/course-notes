# 实施计划

## 1. 输入与坐标

以单人正脸或轻微侧脸为起点，保留头发与下巴；眼镜照片用于观察细线。先按 EXIF 修正方向，再缩放并填充到 384×384。记录实际缩放系数和左上填充量，关键点、边缘、CNN 响应都使用同一画布坐标，输出仅撤销填充，不承诺恢复原图分辨率。

输入图像是 RGB；OpenCV 的 BGR 转换必须显式进行。均值、标准差取自具体权重配置；不执行分类中心裁剪。填充区不参与响应分位数统计，靠近填充边界的响应需要抑制。

## 2. 四步接口

| 函数 | 主要职责 | 返回 |
| --- | --- | --- |
| `prepare` | 方向与尺寸、轻去噪、Sobel、MediaPipe 五官分组 | `Prepared` |
| `extract` | CNN 多层特征、归一化差分、加权与门控 | `Structure` |
| `stylize` | 保边平滑与色板映射、筛线、路径与样条 | `Layers` |
| `compose` | 超采样抗锯齿、颜色合成、撤销填充 | `Result` |

接口与字段见 `src/face_cartoon/contracts.py`。文件读写、模型下载和展示放在外围；函数不修改传入数组。改色板时复用结构响应，切换编码器时复用预处理。

## 3. CNN 提取与门控

使用 [timm 的多层特征接口](https://huggingface.co/docs/timm/feature_extraction)，依据 `feature_info` 选接近 stride 4、8、16 的三个输出，实际层名、通道与尺寸写入运行记录。四种网络都在 `eval` 和无梯度模式下运行；先分别验证 384×384 输入，不假定相同索引对应相同尺度。

每个空间位置的通道向量做 L2 归一化，再计算水平／垂直相邻位置的向量差。对差分幅值按有效区域 q10～q95 归一化并上采样；近常量响应置零，避免把数值噪声放大。

三层固定加权：`S = 0.50 R1 + 0.30 R2 + 0.20 R3`。以单张图像边缘 E 定位，`Q = E × (0.25 + 0.75 S)` 决定候选支持度。S、Q 都不是概率。CNN 不恢复原图缺失的线条，也不直接生成颜色。

## 4. 五官与渲染

[MediaPipe Face Landmarker](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker/python) 只用于粗粒度眼、眉、嘴、脸颊位置。检测失败时明确关闭辅助；不绘制全部网格、不补画被遮挡的五官，也不把关键点或边缘预先叠到 CNN 输入。

颜色层使用保边平滑和 12 色自然暖色板，在 Lab 空间就近映射，压制孤立色点。颜色映射是否适合照片需实际观察；它不是肤色语义分割。

线条沿原图梯度法向做非极大值抑制，以高低阈值滞后连接并过滤短分量；眼嘴阈值乘 0.8、脸颊乘 1.3。密度与门控规则在四模型间保持一致，记录各次实际阈值。实际实现以共享 E 的分位数设阈值，避免对每张 Q 重新定标抵消 CNN 门控。

有序路径在端点和交叉处分段，闭环独立处理。弧长重采样后使用 SciPy 参数样条；保持端点、必要时保留五官急转锚点。拟合曲线到原路径的距离超过约 1.5 像素时减弱平滑或退回折线，不连接远处断口。最终用两档线宽、深棕墨色，在 3 倍画布画线后缩回，按覆盖率合成。

## 5. 实施顺序

| 阶段 | 要做的事 | 完成证据 |
| --- | --- | --- |
| A | 补齐依赖，下载 ResNet50；跑通单张照片 | 输入输出尺寸正确，真实权重版本可追溯 |
| B | 三尺度响应与边缘门控 | 显示 S、E、Q；关闭门控后确实改变笔画 |
| C | 五官辅助与有限样条 | 五官位置合理，回退状态和偏移可查 |
| D | 接入 SE-ResNet50、EfficientNetV2-S、MobileNetV3-Large | 同一照片、统一参数、四列实际结果 |
| E | 整理三类图与简短说明 | 至少正脸和眼镜／侧脸对照，保留典型问题 |

首轮不开展神经网络训练、夸张变形、自动背景分割、视频处理或应用打包。先根据实际照片处理线条与配色；若四模型差异小，就说明统一渲染器在视觉效果中占主导。
