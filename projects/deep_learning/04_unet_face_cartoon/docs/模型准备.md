# 模型准备

必需：UNet、photo2cartoon 生成器、SFD 检测与 2D FAN 关键点权重。四者均已下载并在真人流程中运行。
不需要：TensorFlow 1.x、`seg_model_384.pb`、Face ID 训练用识别网络、单独训练数据集。

```powershell
uv run python scripts/download_models.py unet
uv run python scripts/download_models.py photo2cartoon-bundle --extract-generator
uv run python scripts/download_models.py sfd
uv run python scripts/download_models.py fan
uv run python scripts/download_models.py unet --check
uv run python scripts/download_models.py photo2cartoon-bundle --extract-generator --check
```

UNet 官方入口在 `models.json`。生成器的 [Google Drive](https://drive.google.com/open?id=1lsQS8hOCquMFKJFhK_z-n03ixWGkjT2P) 指向 226,844,549 字节 ZIP；只提取 `photo2cartoon_weights.pt`，不展开其他资料。[百度网盘备用](https://pan.baidu.com/s/1MsT3-He3UGipKhUi4OcCJw)，提取码 `y2ch`。

```powershell
# 官方可选格式，不会自动替换主路线
uv run python scripts/download_models.py photo2cartoon-onnx
uv run python scripts/check_models.py unet --fetch-source --device cuda
uv run python scripts/check_models.py photo2cartoon --fetch-source --device cuda
```

清单固定的是从官方入口下载后本地计算的 SHA256，不宣称作者签名。安全加载使用 `weights_only=True`，严格匹配结构，不能为旧模型自动降级为任意 pickle 执行。ONNX 目前只下载并校验，尚未运行。

关键点缓存限制到本项目 `models/torch/hub/checkpoints`，SFD 约 89.8 MB、FAN 约 95.6 MB。地址来自 face-alignment v1.5.0，文件哈希也与官方文件名中的短哈希一致。正式推理会先校验两者，再创建 `FaceAlignment`；禁用 `torch.compile`，不自动下载缺失权重。

不要直接运行旧版 `utils.Preprocess`，否则会连带导入已替换的 TensorFlow 分割器。不得通过 Cookie、关闭 TLS 或账号凭据绕过网盘权限。
