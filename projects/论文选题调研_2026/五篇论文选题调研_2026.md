## 3. 论文一：AIEC

**Activation with Intrinsic-Extrinsic Consensus**

- 论文：[PMLR 官方页面](https://proceedings.mlr.press/v306/qiu26e.html)
- 代码：[horrible-dong/AIEC](https://github.com/horrible-dong/AIEC)
- 本地代码：[AIEC](./AIEC/)
- 复现等级：**较容易**

### 3.1 它要解决什么问题

神经网络中每个通道可以看成一条“信息传送带”。传统 ReLU、GELU 或简单阈值只观察当前数值是否大，却没有专门判断“这条传送带是否真的对分类有用”。噪声通道也可能被激活，之后层层传播，干扰最终决策。

### 3.2 核心方法

AIEC 把“通道是否重要”拆成两个角度：

1. **Intrinsic Activation-Counting Unit**：统计一个通道在训练过程中被激活的频率，类似观察传送带平时有多忙。
2. **Extrinsic Decision-Making Unit**：学习该通道对最终决策的贡献，类似观察主管在最终决策时是否经常参考这条传送带。
3. **Consensus Gatekeeping Unit**：只有两个角度达成共识，通道才继续通过；长期不活跃或对决策帮助小的通道被压制。

可以用一个简化门控式理解：

\[
\tilde h_c = h_c\,g_c,\qquad
g_c=\mathbf 1[\text{intrinsic}_c\text{ 与 }\text{extrinsic}_c\text{ 足够一致}],
\]

其中 (c) 是通道编号，(h_c) 是原始通道输出，(g_c) 是门控结果。实际实现还配有 gate loss，使模型主动形成稀疏表示。

### 3.3 实验怎样做

仓库提供 `configs/relu.py`、`configs/gelu.py` 和 `configs/aiec.py`，可在相同模型、数据和训练策略下替换激活函数。默认配置包含 CIFAR-10/100、ViT-Tiny 等实验；数据可自动下载到 `--data_root`。比较指标包括分类准确率、激活稀疏度和不同网络结构上的泛化表现。

推荐的课程复现实验：

1. 在 CIFAR-100 上跑 ReLU、GELU、AIEC 三个配置。
2. 固定模型和随机种子，仅替换激活模块。
3. 记录 Top-1 accuracy、非零激活比例和训练曲线。
4. 将 `gate_loss_coef` 从默认值改小或设为 0，观察稀疏性和准确率变化。

官方环境是 Python 3.8、PyTorch 1.13.1+cu117；单卡入口为 `python main.py --config configs/aiec.py`，评估时增加 `--resume ... --eval`。完整 300 epoch 训练可能较久，但课程报告可以先做小 epoch 的趋势复现，再引用论文完整结果。

### 3.4 适合作业的原因和风险

优点是问题单一、图示直观、代码结构清楚、数据无需另行申请。风险是 AIEC 的统计门控和 gate loss 需要结合论文公式解释，不能只把它说成“又一个激活函数”；另外要区分“训练时稀疏”和“推理时真的减少计算量”。

**适合的报告主线**：传统激活只看数值 → AIEC 同时看激活频率和决策贡献 → 共识门控 → 稀疏性/准确率实验 → gate loss 消融。

## 4. 论文二：NT-SSM

**Rethinking Contrastive Learning for Graph Collaborative Filtering: Limitations and A Simple Remedy**

- 论文：[PMLR 官方页面](https://proceedings.mlr.press/v306/lee26w.html)
- 代码：[geon0325/NT-SSM](https://github.com/geon0325/NT-SSM)
- 本地代码：[NT-SSM](./NT-SSM/)
- 复现等级：**最容易，首选**

### 4.1 直观问题

推荐系统可以画成二部图：左边是用户，右边是物品，边表示“用户喜欢/点击过物品”。多跳传播后会出现四类邻居关系：用户-用户（UU）、物品-物品（II）、用户-物品（UI）、物品-用户（IU）。

原来的 Sampled Softmax（SSM）损失像给四类邻居使用同一把尺子，默认它们对表示更新的作用相同。论文的观察是：实际推荐中真正有用的邻居往往只是结构相似的一部分，而且四种关系的相似性和更新方向并不相同。

### 4.2 核心方法

NT-SSM 在对比目标中为四类邻居引入类型感知的权重：

\[
\mathcal L_{\text{NT-SSM}}
 =\mathcal L_{UU}(\alpha_{uu})+
 \mathcal L_{II}(\alpha_{ii})+
 \mathcal L_{UI}(\alpha_{ui})+
 \mathcal L_{IU}(\alpha_{iu}),
\]

并通过温度参数 \(\tau\) 控制正负样本分布的尖锐程度。四个 \(\alpha\) 并不是新增网络参数，而是控制不同邻居类型的更新动态，因此改动小、容易插入 LightGCN、SimGCL 和 NCL。

可以把它想成给推荐系统配了四位不同的顾问：用户相似性、物品相似性、用户到物品、物品到用户各自提供意见，系统不再强行让四个人用同一种评分标准。

### 4.3 实验怎样做

代码已经包含 LastFM、MovieLens-1M、Yelp2018、Amazon-Book 的 train/valid/test 划分。主入口命令见 README 和 `run.sh`，例如：

```bash
python main.py --gpu 0 --dataset ml-1m --model_name LightGCN_NT \
  --model_type graph --item_ranking 10,20,40 --embedding_size 64 \
  --epoch 200 --batch_size 2048 --learning_rate 0.001 \
  --reg_lambda 0.0001 --n_layer 2 --alpha_uu 1.0 --alpha_ii 1.0 \
  --alpha_ui 1.0 --alpha_iu 1.0 --loss_type ssm --tau 0.2
```

去掉模型名中的 `_NT` 就是标准 SSM 基线；换成 `SimGCL_NT` 或 `NCL_NT` 可以检验方法是否依赖 LightGCN。实验指标是 Recall/NDCG 等 Top-K 推荐指标，代码会将日志和 embedding 保存到 `logs/`、`embs/`。

推荐的有限复现：先在 ML-1M 上把 epoch 改成 5 或 20，跑 LightGCN 与 LightGCN_NT；随后只改变四个 alpha，画出 NDCG@20 的变化；最后换 SimGCL_NT 做一个跨骨干验证。这套实验非常适合写成“基线—改进—超参数/类型消融—结论”。

### 4.4 适合作业的原因和风险

这是五篇中最适合课程作业的一篇：数据已经在仓库里，标准方法和改进方法可一键切换，改动集中在损失函数，训练逻辑容易阅读。需要注意推荐系统的评估不是普通分类准确率，报告中应解释 leave-one-out/Top-K 评价、Recall@K 和 NDCG@K 的含义。

**适合的报告主线**：用户-物品二部图 → 多跳邻居类型 → SSM 的统一更新问题 → NT-SSM 四类权重 → 三个骨干和四个数据集实验 → 类型消融。

## 5. 论文三：预训练模型中的统计量与类增量学习

**On the Power of Statistics in Class-Incremental Learning with Pretrained Models**

- 论文：[PMLR 官方页面](https://proceedings.mlr.press/v306/cao26h.html)
- 代码：[HdTgon/baseCIL](https://github.com/HdTgon/baseCIL)
- 本地代码：[baseCIL](./baseCIL/)
- 复现等级：**中等**

### 5.1 直观问题

类增量学习要求模型分阶段认识新类别，例如第一阶段只见到猫狗，第二阶段再见汽车飞机。普通神经网络会在学习新类别时覆盖旧知识，即灾难性遗忘。

论文的关键设定是：冻结一个已经很强的预训练视觉骨干（例如 CLIP），不再持续更新大网络，而是为每个类别保存特征分布的统计量。可以把骨干看成固定相机，把每个类别看成相机拍到的一团点云；新阶段只需为新类别建立点云统计，同时保留旧类别统计。

### 5.2 核心方法

对类别 (k) 的预训练特征 (z)，估计均值和协方差：

\[
\mu_k=\frac1{n_k}\sum_i z_i,
\qquad
\Sigma_k=\frac1{n_k-1}\sum_i(z_i-\mu_k)(z_i-\mu_k)^\top.
\]

分类时可用高斯模型或高斯混合模型比较测试特征属于哪个类别：

\[
\hat y=\arg\max_k\;\log p(z\mid\mu_k,\Sigma_k)+\log p(k).
\]

这样旧类别的“记忆”是统计量而不是一大批旧图像，既降低存储，又避免反复微调造成遗忘。论文实验说明，仅靠预训练表示和类级统计量，就能恢复联合训练性能的相当部分。

### 5.3 实验与代码

仓库基于 PILOT，配置文件在 `exps/gmm_ensemble/`，覆盖 CIFAR、CUB、Food、Aircraft、Cars、ImageNet-R、SUN、UCF 等数据。入口是：

```bash
conda env create -f baseCIL.yml
python main.py --config exps/gmm_ensemble/cifar.json
```

`utils/data.py` 中需要修改数据路径。每个增量任务结束后，代码记录 Top-1/Top-5 accuracy 曲线，并输出平均准确率。课程复现可从 CIFAR 配置开始，先缩小任务数量或数据规模，比较：冻结骨干 + 统计量、普通微调、联合训练上界。

### 5.4 适合作业的原因和风险

理论叙事非常好：参数记忆换成分布记忆，能自然联系高斯判别、原型网络和灾难性遗忘。主要风险是仓库不自动下载数据，数据目录依赖 PILOT 约定，CLIP/预训练权重和 GPU 显存也会影响运行。因此更适合做“一个数据集的局部复现 + 统计量可视化 + 增量曲线”，不要一开始承诺重现论文所有数据集。

**适合的报告主线**：类增量学习和遗忘 → 冻结预训练表示 → 类条件均值/协方差 → GMM 分类器 → 增量准确率和遗忘率实验。

## 6. 论文四：Dual-Steering 与 Softmax 信息几何

**The Information Geometry of Softmax: Probing and Steering**

- 论文：[PMLR 官方页面](https://proceedings.mlr.press/v306/park26p.html)
- 代码：[KihoPark/dual-steering](https://github.com/KihoPark/dual-steering)
- 本地代码：[dual-steering](./dual-steering/)
- 复现等级：**中等偏难，理论深**

### 6.1 直观问题

表示空间里走一小步，并不代表模型输出概率只发生一小步。Softmax 把 logits 变成概率分布，概率分布本身有自己的几何结构。普通欧氏 steering 像在地图上画直线，却没有考虑“模型输出分布的真实距离”。

### 6.2 核心方法

论文把 softmax 输出看成概率流形，用与 Fisher 信息相关的度量描述局部变化。给定一个想增强的概念方向，Dual-Steering 每一步都根据当前概率分布重新计算更合适的方向，使目标概念增强，同时尽量少影响其他概念。

代码中 `e_steering` 是欧氏基线，直接执行

\[
z_{t+1}=z_t+\eta d,
\]

而 `m_steering` 会根据当前 logits、softmax 概率和表示矩阵近似求解局部几何下的方向；实现使用共轭梯度求解线性系统，再沿该方向更新。论文的理论主张是：在给定目标变化的条件下，dual 路径能最小化非目标概念的附带变化。

### 6.3 实验与代码

仓库实现 Gemma-3-4B 的语言模型实验和 MetaCLIP-2 的视觉语言实验。`03_llm_steering.py`、`04_llm_metric.py` 对 C4 上下文做 steering 和指标计算；`05_clip_object.py`、`06_clip_coco.py` 做图像实验；`07_visualization.ipynb` 负责画图。仓库还提供 counterfactual token pairs 和 synthetic object 数据说明。

课程级复现建议优先做 CLIP 子实验：选择少量概念对，比较 Euclidean 与 Dual 两条路径的目标概念概率、非目标 KL 散度、排序变化和路径长度。若没有 Gemma-3-4B 条件，可以只复现 `information_geometry` 中的几何计算和小规模 CLIP 实验，报告中明确这是局部复现。

### 6.4 适合作业的原因和风险

优点是理论深度和图形表达很强，能讲清楚“为什么欧氏距离不够”。风险是大模型、C4 上下文和 Google Drive 数据带来下载与显存成本，论文中的最优性证明也需要较多信息几何背景。它适合数学基础较好、愿意把重点放在原理和指标设计上的同学。

**适合的报告主线**：logit 空间与概率空间 → softmax 几何 → 欧氏 steering 的副作用 → dual 度量和共轭梯度 → 目标/非目标指标 → LLM 与 CLIP 实验。

## 7. 论文五：CFR 多模态异常检测

**Remove the Ambiguity: Few-shot Multimodal Anomaly Detection Using Crossmodal Feature Replacer**

- 论文：[PMLR 官方页面](https://proceedings.mlr.press/v306/guo26ai.html)
- 代码：[Yuan-Honoka-Guo/CFR](https://github.com/Yuan-Honoka-Guo/CFR)
- 本地代码：[CFR](./CFR/)
- 复现等级：**偏难**

### 7.1 直观问题

工业检测同时有 RGB 图像和 3D 点云。理想情况下，两种模态应该互相验证；但一个 2D 外观可能对应多个 3D 形状，反过来也一样，直接回归会产生“平均答案”，把异常细节抹平。

可以把 RGB 和点云想成两个检验员：一个检验员根据另一人的描述进行猜测时，可能说出一个模糊的平均答案。CFR 的做法是：先判断这个猜测是否可靠；不可靠时，从正常样本记忆库中找一个更可信的特征替换它。

### 7.2 核心方法

CFR 包含四步：

1. **双向循环重建**：学习 2D→3D 和 3D→2D 的映射，同时要求绕一圈回到原特征，减少单向回归的不确定性。
2. **模态特定记忆库**：保存 RGB、点云及配对特征，作为正常样本参考。
3. **可靠性判断**：估计重建特征是否可能是平均化/错误匹配。
4. **特征替换与异常评分**：将不可靠重建替换为高置信正常特征，再计算图像级和像素级异常分数。

训练代码中的总损失可以概括为四个余弦重建项：

\[
\mathcal L=\mathcal L_{2D\to3D}+\mathcal L_{3D\to2D}
 +\mathcal L_{2D\to2D}^{cycle}+\mathcal L_{3D\to3D}^{cycle}.
\]

### 7.3 实验与代码

官方脚本明确分为：`01_train_*` 训练 CFR、`02_mb_cons_*` 构造 memory bank、`03_atten_train_*` 训练 attention retriever、`04_eval_*` 评估。支持 MVTec 3D-AD 和 Eyecandies，使用 DINO RGB 特征、PointMAE 点云特征，指标包括 AUROC 和 AUPRO。

推荐的局部复现是只选 MVTec 3D-AD 的一个类别（如 `bagel`），设置 `FEW_SHOT=4`，先完成四阶段流程，再与不使用 replacement 的 CFM 基线比较。报告中可展示一个正常样本、一个异常样本的 RGB/点云/异常热力图，直观解释替换前后的差异。

### 7.4 适合作业的原因和风险

研究问题鲜明、可视化效果好，也确实有深度；但它依赖 CUDA、PointNet++ 自定义算子、DINO/PointMAE 权重和 CFM 的预处理格式，数据准备最容易出错。若课程更看重“代码阅读和实验报告”而不是大规模复现，CFR 可以作为备选；若希望稳妥完成，优先选 NT-SSM 或 AIEC。

**适合的报告主线**：跨模态一对多歧义 → 双向循环重建 → 正常记忆库 → 可靠性替换 → few-shot MVTec/Eyecandies 实验。

## 8. 最终选择建议

### 首选：NT-SSM

它同时满足源码完整、数据齐全、改动集中、基线明确和实验容易缩小。Presentation 可以用二部图、四类邻居、损失函数和 Top-K 曲线讲满 20 页；期末报告也能自然加入参数敏感性和不同骨干实验。

### 次选：AIEC

如果更喜欢计算机视觉/神经网络基础，AIEC 是更稳的选择。只需围绕激活统计、决策权重、共识门控和稀疏性做主线，代码入口清晰，CIFAR 数据准备简单。

### 有理论兴趣时选 Dual-Steering

它最有“深度”，但需要主动控制复现范围。建议把 CLIP 小实验作为可交付结果，把 LLM 实验作为论文方法的延伸，不要把完整大模型复现当作硬性承诺。

### 想做视觉工程时选 CFR

它的图像和异常热力图最容易让 Presentation 生动，但必须尽早验证 CUDA、PointNet++、权重和数据预处理。若环境不稳定，应及时换成 AIEC 或 NT-SSM。

## 9. 建议的报告与 Presentation 结构

5 页以上阅读报告可以按以下比例组织：问题和背景约 1 页，方法与公式约 2 页，实验设置和结果约 1.5 页，局限性与自己的复现约 1 页。20 页以上 Presentation 可拆成：动机 3 页、背景 3 页、核心方法 6 页、实验设置 3 页、结果/消融 4 页、复现和思考 3 页。

邮件提交时仍需使用复旦邮箱，并在标题中写姓名和学号。报告意愿建议：NT-SSM/AIEC 选择“积极”较合适；统计 CIL 和 Dual-Steering 视实际读懂程度选择“积极/一般”；CFR 在完整跑通环境前选择“积极”风险较高。
