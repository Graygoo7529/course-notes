# 公开测试人像与许可

只用于本地课程实验，不代表人物认可或代言本项目。下载脚本使用 Wikimedia Commons API 取得约 1280 像素宽的缩略版本，验证图片格式并记录元数据。固定文件哈希见 `samples.json`，原始元数据保存在 `data/public/*.json`。

| 样例 | 作者／来源 | 许可 |
| --- | --- | --- |
| [Liu Yifei Portrait1](https://commons.wikimedia.org/wiki/File:Liu_Yifei_Portrait1.jpg) | 刘亦菲吧官方 | [CC BY-SA 2.5](https://creativecommons.org/licenses/by-sa/2.5/) |
| [Commander Eileen Collins](https://commons.wikimedia.org/wiki/File:Commander_Eileen_Collins_-_GPN-2000-001177.jpg) | Robert Markowitz / NASA | Commons 标注美国联邦政府作品公共领域；仍遵守 [NASA 媒体使用说明](https://www.nasa.gov/nasa-brand-center/images-and-media/) |
| [President-elect Barack Obama](https://commons.wikimedia.org/wiki/File:U.S._President-elect_Barack_Obama_Official_Portrait.jpg) | Obama-Biden Transition project | [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)；不因是总统照片就自动称为公共领域 |

图像改动包括缩略下载、方向校正、对齐裁剪、置白、区域编辑和漫画生成。离线页面携带署名与来源链接；发布 CC BY-SA 图片的派生作品时须保留署名、注明改动并遵守相同方式共享。肖像权、模型许可和数据集许可是独立问题，不把图片许可等同于所有商业用途都可用。

本仓库默认忽略照片与生成图片，仅保存代码、来源说明和校验值。`--input` 使用自有照片时不会自动取得授权，分享前仍须确认。
