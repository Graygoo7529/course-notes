# 安装与运行

## 1. 环境和模型

本机已验证 Node 24.9、npm 11.6、MSVC、Rust、WebView2 和 Conda d2l。PowerShell 使用 `npm.cmd`，避免 `npm.ps1` 执行策略问题。

```powershell
conda activate d2l
Set-Location 'B:\LearnSpace\Course Notes\projects\realtime_cartoon_camera'
python -m pip install -r python/requirements.txt
npm.cmd ci
python python/export_openvino.py --size 256
python python/export_openvino.py --size 384
```

以上是重建环境的指令，本次已经执行。Python 的其余依赖复用 `../cnn_face_cartoon/requirements.txt`；原项目的 MobileNetV3 权重、MediaPipe task、`config.json` 必须存在。新项目 `models/` 下每档有 `.xml`、`.bin`、`.json` 三个文件，导出的是三个特征张量。

## 2. 桌面运行

```powershell
$env:CARTOON_PYTHON = (Get-Command python).Source
$env:Path = 'C:\Users\Aogo\.cargo\bin;' + $env:Path
npm.cmd run tauri dev
```

开启相机后，先申请视频权限，再启动算法。默认 OpenVINO CPU；停止后可在“运行信息”选择 PyTorch CPU。未检测到人脸时仍可处理整幅图，但不使用五官区域阈值。

调试可执行文件构建：

```powershell
npm.cmd run tauri build -- --debug --no-bundle
& .\apps\desktop\src-tauri\target\debug\realtime-cartoon-camera.exe
```

可执行文件仍依赖仓库中的 `python/worker.py`、上一项目及 d2l，并未打包 Python sidecar。`CARTOON_PYTHON` 用于指定解释器；不设置时 Tauri 使用 PATH 中的 `python`。导出的 PNG 保存到系统下载目录。

## 3. 浏览器开发

```powershell
$env:CARTOON_PYTHON = (Get-Command python).Source
npm.cmd run dev
```

访问 <http://127.0.0.1:1420>。Vite 插件启动本机 worker；图像使用二进制 WebSocket 传输，浏览器也真正执行 CNN 推理。浏览器保存通过下载功能完成。Vite 仅绑定本机地址，不作为手机远程推理服务。

停止相机释放视频和推理会话；开发服务器保留空闲 worker，结束 Vite 后清理进程。Tauri 停止相机时同时终止 worker。窗口进入后台会关闭相机，返回后重新开启。

## 4. 检查

```powershell
python -m ty check --python "$env:CONDA_PREFIX\python.exe"
python -m unittest discover -s tests -v
npm.cmd test
npm.cmd run build
cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml
```

本机可能从其他 Conda 环境启动 `ty` 的可执行入口，所以显式传入 d2l 解释器，避免错误地解析 `common` 环境。Python 测试需要原项目 `data/input/grace_hopper.jpg` 和已导出的两个模型；缺少示例照片时会明确跳过，不能把跳过算为模型验证通过。

## 5. 常见问题

- **相机无法打开**：检查系统相机隐私设置、WebView／浏览器授权和其他程序占用。仅请求视频，不请求麦克风。
- **模型找不到**：检查两档 IR 及上一项目模型目录，重新运行导出命令。
- **端口被占用**：桌面开发与浏览器开发不要同时启动两个 Vite。
- **第一次启动较慢**：初始化包括 Python 导入、两档模型编译预热和 MediaPipe 创建；界面显示模型预热阶段。
- **实际 FPS 较低**：运行信息统计的是漫画结果，不是原始视频 FPS。实现主动限制采样上限约 10 次／秒，并在忙时跳帧。

Android 工具链与手机运行条件见 [Android 文档](../native/android/README.md)。
