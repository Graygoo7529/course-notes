## 方法与样例

冻结 ResNet50、SE-ResNet50、EfficientNetV2-S、MobileNetV3-Large，从三尺度特征得到结构支持 S，以 Q=E(0.25+0.75S) 调节图像边缘。经过五官阈值辅助、骨架追踪、有限样条、固定色板和抗锯齿合成，得到每个模型的实际成图。没有训练或微调。

三张输入来自两个人物：已有本地正脸眼镜照片、Matplotlib 公开样例照片，以及本地照片 RGB 乘 0.30 的派生暗图。原始照片分别是 150×197 和 512×600；前者放大不会产生真实新细节。暗图只用于观察流程在弱光下的表现，不算独立人物样本。

所有模型使用同一 384×384 工作画布；去掉填充后，本地人像输出为 292×384，公开样例为 328×384。三个输入均检测到关键点，完整成图共 12 组。

## 观察

四种模型的整体风格接近。固定配色主导了色块外观，模型差异主要落在线条保留、眼镜附近细节、发丝和碎纹理上，不能据此做质量优劣排名。

本地正脸能保留主要五官与眼镜，但脸部明暗分区较硬；公开样例保留了帽子、衣领和背景，同时皱纹与复杂背景产生较多线条。强暗光派生图的脸部和背景容易落入相同深棕色，温和增强无法恢复足够层次。这里保留原始参数和失败倾向，没有为不同模型单独调参。

## 运行与检查

设备为 CPU，PyTorch `2.14.1+cpu`，torch 线程数 6。下表是三个输入的实测范围；CNN 列包含一次预热后的前向和结构计算，渲染列包括共享颜色层及笔画合成，不包括图表写盘、权重加载或关键点检测。

| 模型 | CNN＋结构 | 颜色＋笔画 |
| --- | --- | --- |
| ResNet50 | 0.101～0.107 s | 0.275～0.413 s |
| SE-ResNet50 | 0.104～0.116 s | 0.265～0.412 s |
| EfficientNetV2-S | 0.091～0.121 s | 0.274～0.448 s |
| MobileNetV3-Large | 0.021～0.025 s | 0.264～0.435 s |

最终运行重新执行了全部 12 次 CNN 提取，预处理沿用此前已检测成功的缓存；含权重加载、预热、渲染和报告导出的计时约 11.1 秒，未计入 Python 依赖导入。少量样例和单次测量不足以作为性能基准。

实现检查结果：

- 四模型的颜色层逐像素相同，结构支持图两两不同，输入输出尺寸符合撤销填充后的画布。
- 三张照片关闭 CNN 门控后均改变笔画，具体见下表；这里只检查 CNN 是否生效，不评价漫画质量。
- 最终曲线相对原始骨架折线的最大采样偏移为 1.500 像素，未超过 1.5 像素约束。
- 改为另一色板和密度后，复用全部缓存完成重绘；通过禁止模型构造的检查确认没有重新加载 CNN／关键点模型，NPZ 内容不变。
- `pip check`、`ty check`、7 项单元检查通过。离线浏览测试覆盖 12 种选择组合、PNG 下载字节核对，以及 390 像素窄屏；没有脚本错误、图片加载失败或页面横向溢出。

| 样例 | 关闭 ResNet50 门控后变化的笔画像素 |
| --- | --- |
| 本地人像 · 正脸与眼镜 | 11573 |
| 公开示例 · 眼镜与复杂背景 | 11418 |
| 同图暗光派生 · 压力检查 | 10729 |

变化像素以有效区内笔画覆盖率绝对差大于 0.05 计数，仅用于排查门控是否被忽略。各模型的层名、张量形状、阈值、路径和权重哈希均保存在模型子目录 `run.json`／`structure.json`。
