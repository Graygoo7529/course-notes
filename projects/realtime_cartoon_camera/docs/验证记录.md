## 性能快照

0.1.2 桌面回归的模拟相机测试：OpenVINO CPU、256 预览，约 10 FPS；最近一帧算法约 62.5 ms，采样到显示约 66.5 ms；模型会话初始化约 1813 ms。初始化统计不含启动 Python 和导入库的时间。界面 FPS 统计实际显示的漫画帧；采样有约 10 FPS 上限，模拟源本身也限制了帧率。这不是手机性能数据。

原生 C++ 20 次预热后 CNN 推理均值：256 约 1.68 ms，384 约 3.48 ms。这里只计 CNN，不含图像预处理、人脸、结构响应、渲染、编解码或传输，因此不能据此推算整条相机链路 FPS。

这些数值是一次本机检查的快照，不是稳定性或不同设备性能保证。没有进行数分钟真机温度、内存与持续运行测试。

## Android 安装包

文件：`dist-android/CartoonCamera-arm64-debug.apk`，版本 0.1.2（versionCode 1002），98,769,649 字节（约 94.2 MiB）；Android 10/API 29 起，目标 API 36，只有 arm64-v8a。SHA-256：`68da24c6b56050bd89fb1935a2cb2827db98dc9aff0a55518f194d432ea1bc21`。

0.1.0 的手机反馈为 `crypto.randomUUID is not a function`，对应模型初始化前的会话编号生成。0.1.1 改为检测 API：可用时使用原生 UUID，否则由 `getRandomValues` 生成 UUID；两者均不可用时使用页面时间前缀与递增序号。该编号只用于区分相机会话及过滤过期帧，不是鉴权令牌。[Web Crypto 规范](https://w3c.github.io/webcrypto/#Crypto-interface)对 randomUUID 标记了安全上下文要求；尚未确定该手机是 WebView 版本还是页面环境导致接口不可用。

修复版通过 TypeScript/Vite 构建、7 项前端测试、Python 类型检查、APK 签名和资源检查。签名证书与 0.1.0 相同，可覆盖安装；用户已完成手机端验收。

0.1.1 的手机反馈：拍照成片可用，但原图/实时漫画不显示，拍照后页面无法滚动。`tests/mobile_ui_smoke.py --probe` 在模拟条件下复现：禁用 aspect-ratio，并令视频显示回调不执行，预览高度降为 2 px、实时提交数为 0，而拍照仍成功；结果处于 fixed 全屏遮罩。

0.1.2 用百分比 padding 支撑预览比例，以 100 ms 定时检查替代视频显示回调，手机结果卡片改为文档流。相同模拟条件下预览高度为 476.7 px，实时提交恢复；原图与漫画的截图都有实际图像像素，触摸滑动改变页面 scrollY，保存调用、返回预览、横屏和停止清理检查均通过。报告及色条截图位于 `.cache/qa/mobile-regression/`。该测试使用模拟摄像头与 Android 桥接替身，只验证 UI，不重复宣称 Android 原生推理验证。桌面另用真实 OpenVINO worker 完成预览、拍照、下载、暂停恢复和重启回归。

[视频帧回调规范](https://wicg.github.io/video-rvfc/#dom-htmlvideoelement-requestvideoframecallback)将回调与画面提交给合成器关联；因此隐藏视频的采样不再依赖此回调。实际手机的 WebView 版本尚未取得，模拟复现不是对其版本的判断。

使用 ONNX Runtime Android 1.23.2、OpenCV 4.12.0、MediaPipe 0.10.26。导出数值对照在 Windows PyTorch/ONNX Runtime 1.31.1 上执行；它核对导出模型，不代表 Android 运行时已经逐值验证。Kotlin 单测在宿主 JVM 上执行，不包含相机和 Android 原生推理。

构建环境：JDK 21.0.8、Gradle 9.6.1、Android Gradle Plugin 9.3.1、SDK/Build Tools 36、NDK r28c。首次下载曾遇到 Java 代理证书和 Maven TLS 握手问题，已使用 Windows 根证书库与 Maven Central 官方 repo1 端点解决。无需 adb 即可构建与手动安装，详见 [Android 打包与安装](../native/android/README.md)。

检查脚本 `scripts/verify_apk.py` 生成 `dist-android/payload-verification.json`；构建脚本生成 `SHA256SUMS.txt`。模型、APK 和构建目录不纳入 Git。
