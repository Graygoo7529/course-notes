## 议题识别

识别出当前或潜在的公共关注点、讨论话题或社会议题的过程。属于自然语言处理中的分类问题。
- 基于关键词 -> 概念，关键词 -> 不同概念的组合形成了不同话题
- 基于机器学习 -> LDA
- 基于深度学习 -> BERTopic
- 基于 LLM

### LDA（latent dirichlet allocation）
主题建模，用于发现文档中潜在的主题
- 文档是主题的混合
- 主题是单词的分布
- 对于文档中的每一个词，计算该词属于每个主题的概率，同时考虑主题在词上的分布和文档在主题上的分布
- 无监督学习，LDA 同时利用“文档内部哪些词一起出现”和“这些模式在不同文档中如何重复”，在给定语料上拟合特定单词模式形成主题
- 缺点：适用于长文本；需要设置主题数作为超参数（可用主题一致性校验经验分析该超参数），缺乏自适应性；基于词袋模型，只考虑单词共现，不考虑语义如同义词、关联词等词句信息
