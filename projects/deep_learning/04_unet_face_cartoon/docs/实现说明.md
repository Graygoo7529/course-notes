# 实现说明

## 统一坐标

输入先校正 EXIF 并转 RGB，透明像素合成白底。检测工作图最长边限制为 1600；SFD 检测人脸、2D FAN 预测 68 点，旋转使眼角连线水平，再按官方比例扩展裁剪为正方形。

保留从 EXIF 校正后原图到 512 头像的齐次矩阵 $T$ 及 $T^{-1}$：

$$
\begin{bmatrix}x_p\\y_p\\1\end{bmatrix}
=T_{\mathrm{resize}}T_{\mathrm{crop}}T_{\mathrm{rotate}}T_{\mathrm{working}}
\begin{bmatrix}x_o\\y_o\\1\end{bmatrix}.
$$

缩放按像素中心定义：$x'=s(x+0.5)-0.5$。框外补白；第一版输出规范头像，不贴回照片。原图中已经截掉的发顶不能靠补白恢复。

## 解析与前景

UNet 输入 RGB、512×512、[-1,1]，输出 $1\times19\times512\times512$ logits。只需要标签时直接在类别维 argmax，与 softmax 后 argmax 等价，避免额外保留概率张量。

类别图原样保存；前景取类别 1～15，但不包含颈部、项链、衣服。第一轮真实照片出现衣领被误判成帽子、围巾被误判成头发的孤立块，因此增加单人规则：**保留皮肤像素最多的前景连通域**。

此规则只作用于合成前景，不按面积删除眼睛、嘴唇等类别，也不改原始标签。它会丢失与主体断开的耳饰；报告同时给出原始掩膜、清理结果和移除像素数，便于核对。

## 分区处理

皮肤仅选 `skin=1`，鼻子单独保护。令 $d(p)$ 为区域内到边界的距离，处理权重为

$$
w(p)=\mathbf{1}_{\mathrm{skin}}(p)\min\left(\frac{d(p)}{4},1\right),\qquad
I'(p)=I(p)+\lambda w(p)\bigl(F_{\mathrm{bilateral}}(I)(p)-I(p)\bigr).
$$

双边滤波采用直径 7、颜色尺度 25、空间尺度 5；这是保守起点，不宣称最优。区域外权重严格为零，向内衰减减轻跨边界取样污染；不承诺数学上完全消除双边滤波的所有跨区域影响。

可选发色在 OpenCV Lab 空间保留输入 L，向目标色的 a/b 混合；同样只在头发内部写回。转换到 RGB 时存在色域裁剪，因此“保留亮度”是处理意图而非输出像素绝对不变的保证。该操作默认关闭。

## 生成与输出

未处理和已处理头像使用相同前景置白，再按面积插值降到 256×256。生成器读入 RGB float32 [-1,1]；`eval()`、`inference_mode()`、严格 state_dict 和加载前 SHA256 校验在正式管线中保留。

通常一次解析、两次生成得到对照；若两份生成输入逐像素相同，复用基线输出。区域控制影响输入，不代表生成器只改变局部区域，也不保证准确保持发色。

后处理只有反归一化、有限数值检查、clip、RGB PNG 保存和结果检查。默认不复用输入细粒度掩膜做输出抠图、不叠加照片纹理、不强锐化。展示放大仍是插值，不产生真实高清细节。

## 复现与错误

四份必要权重：UNet、photo2cartoon、SFD、2D FAN，均固定哈希；网络结构来自固定 commit 并核对源码哈希。face-alignment 禁用 Windows 上非必需的 `torch.compile`，避免编译工具链和全局编译缓存。

输入或模型错误不伪造输出。无人脸、多脸、无有效分割前景、NaN/Inf 均报告失败；批量运行保留其他成功样例，最终有任意失败即返回非零退出码。旧输出不自动覆盖，避免图片与参数串批。
