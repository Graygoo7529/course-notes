# 实施记录

## 2026-10-06：最小管道

本轮完成设计 v0.2 的七个函数，并提供命令行入口、可选的矩形与笔划标记窗口，以及中间结果导出。代码位于 `src/cartoon_portrait`：`pipeline.py` 保存核心运算，`selection.py` 收集标记，`cli.py` 串联步骤，`artifacts.py` 管理结果文件与合成图。

接口使用 float32 RGB/RGBA、bool 遮罩和统一的原图坐标。GrabCut 可由矩形或四类标签初始化；提供 `--mask` 时直接复用已确认的二值遮罩。核心处理函数不修改输入，也不打开窗口或读写文件。

### 实现约定

高斯核半径为 $r=\lceil3\sigma\rceil$，核宽 $2r+1$；$\sigma=0$ 时仅保留前景颜色。横纵一维卷积使用反射边界，分子、分母都完成两个方向的卷积后再相除。遮罩外输出为零，不具有前景颜色含义。

描线前使用 OpenCV 的距离标签，将邻近前景灰度延拓到背景；该距离计算采用 $5\times5$ 近似。之后以 $3\times3$ Sobel 核除以 8 计算两个方向，单位阶跃的峰值响应为 0.5。延拓只用于避免占位零值造成假边缘，不会改变人物遮罩，也不恢复发丝颜色。人物外轮廓由 alpha 保留，本版没有额外沿遮罩描黑边。

颜色量化仅作用于 Lab 明度，默认 6 档、混合强度 0.65。量化和提线是两个独立分支。最终 RGB 为 $C(1-\lambda E)$，alpha 为二值遮罩；PNG 保存非预乘 RGBA，浅深背景预览只合成一次。

### 验证结果

使用 `d2l` 的 Python 3.13.14，项目内依赖为 NumPy 2.5.3、OpenCV 4.14.0.94、Pillow 12.3.0，类型检查使用 ty 0.0.84。

`python -m unittest discover -s tests -v` 的 14 项检查全部通过，`python -m ty check` 通过。主要检查了卷积的常量保持与背景隔离、Sobel 响应尺度、量化范围和输入不变性、空遮罩与非法参数、EXIF 方向、中文路径、透明度保存、标签和遮罩复用，以及已有结果不被覆盖。

通过 `python run.py --demo --output outputs/synthetic-baseline` 跑通整条管道。合成图尺寸为 $480\times560$，人物肩部接触画面底边；GrabCut 遮罩与已知前景的 IoU 为 1.0000。该图背景和人物颜色刻意分离，**此数值只验证这张合成图，不代表真实自拍的分割能力**。

已检查生成的六步总览：背景删除、平滑、明度分层、五官描线与最终合成均可观察。图中的头发和衣服也出现了量化边界，说明固定档数可能产生不够自然的色阶；后续应在自拍上判断是否需要减弱量化。

### 下一轮观察

当前没有真实自拍输入。下一轮首先检查人物遮罩是否包含完整头发、耳朵和肩部，然后观察眼眉、鼻翼和嘴唇的描线是否过重，最后在浅、深背景上检查锯齿和背景残色。应先固定遮罩，再修改风格参数，以免混淆分割问题与漫画化问题。

窗口坐标映射和接受流程已有模拟事件测试，实际桌面鼠标操作尚未人工验证。当前没有真实照片的质量评价、运行时间或内存基准。双边滤波、XDoG、连续 alpha 与学习模型保持为后续扩展。

## 2026-10-07：首张照片结果分析

分析对象为 `outputs/20261006-231358-781351`，输入尺寸 $150\times197$，采用全部默认漫画参数。背景已大体移除，RGBA 的 alpha 仅含 0 和 255，且与保存的遮罩完全一致；主要问题依次是保留范围、平滑尺度与明度量化。

初始化标签只包含确定背景 0 和可能前景 3，没有前景/背景笔划。前景候选恰为矩形 $x=24\ldots124,\ y=22\ldots156$（坐标含端点）。矩形顶部穿过头发，底部止于颈部，因此框外的头发和肩部不可能被后续 GrabCut 或漫画化恢复。下一次框选应覆盖期望保留的完整人物区域；若只需要头像，也应完整保留头顶并另行确定自然的裁切位置。

默认 $\sigma=1.5$ 对应 $11\times11$ 高斯核。在这张低分辨率照片上，平滑图中的镜框、眼睛和嘴部已经明显变模糊。明度 6 档、混合强度 0.65 随后将原本渐变的光照变成额头斜向分界和脸颊局部亮斑；这些色块在叠加线条之前就已出现。

在同一遮罩下，分别只将 sigma 调到 0.6、只将 amount 调到 0.3、只将 strength 调到 0.5，并额外生成三项一起调整的结果。对照保存在 `outputs/20261006-231358-781351-analysis`，每幅图仅为显示而最近邻放大 3 倍。

减弱平滑能保留更多镜框细节，也会使原来的 Sobel 参数画出更多杂线；减弱量化可缓和明暗分界，但无法恢复已经模糊的五官；只减弱描线不能消除色阶斑块。三项合调的结果可作为下一轮起点，仍不视为最佳漫画效果。

下一轮优先放大小图标记预览、修正人物范围，再调整小图的平滑尺度与风格强度。进一步的方法替换应先比较保边平滑，并继续区分人物轮廓、五官结构与光照渐变。原始结果和处理代码在本轮分析中保持原样。


## 2026-10-07：逐通道结构融合实现

将设计 v0.5 实现为默认函数管道：逐通道遮罩高斯与 Sobel/Scharr、二阶结构矩阵融合、颜色/结构邻接权重、明度与色度的 WLS 平滑、软明度映射、法向非极大值抑制、双阈值连通筛选和透明合成。旧版高斯、硬量化、灰度 Sobel 通过 `--pipeline baseline` 保留。小图交互最多放大 4 倍；照片用双线性、标签用最近邻插值，画笔和框选按原图像素映射。

颜色平滑由四邻域矩阵无显式构造地执行，使用 Jacobi 预条件共轭梯度，内部 float64，真实残差达标后才返回 float32；超出迭代上限时不导出部分结果。没有增加依赖。

### 验证结果

`python -m unittest discover -s tests -v` 的 **32 项检查全部通过**，`python -m ty check` 通过。新增检查覆盖：遮罩归一化高斯与二维核等价；灰度相等的彩色阶跃；相同 RGB 梯度、反向梯度、方向退化和旋转；WLS 与独立稠密方程求解、常量保持、遮罩断开、残差及未收敛报错；软明度映射单调与恒等退化；连接弱边与孤立弱边；细化、边缘轮廓；原图坐标、非整数放大标签、画笔尺度和修改后不可误接受旧分割；端到端结构输出与 baseline 对照。

合成测试图分割 IoU 为 1.0000，结构管道成功生成透明 PNG；这只验证合成图。使用已存在的 $150\times197$ 一寸照和原二值遮罩运行，结构 WLS 最大报告相对残差约 $8.84\times10^{-6}$、41 次迭代，核心处理约 0.07 秒（不含读取、分割与导出，单次观测）。透明结果及原始特征分别见[六步对照](outputs/structure-v06-selfie/overview.png)、[通道融合对照](outputs/structure-v06-selfie/features_overview.png)和 [features.npz](outputs/structure-v06-selfie/features.npz)。浅色及深色背景预览、完整参数和求解信息在同一输出目录。

### 图片观察

新旧并排图见 [比较图](outputs/structure-v06-selfie/comparison.png)。新结果削弱了旧版硬量化造成的额头/脸颊突兀斑块，保留眼镜轮廓与嘴唇；当前描线较轻、色阶也偏温和，尚不是最终风格定稿。逐通道、灰度差分、幅值汇总和结构矩阵图以同一强度尺度保存；本例几种响应相近，不支持把可见改善单独归因于多通道融合。

这次复用了之前的遮罩与标签，因此人物头顶和肩膀仍按旧矩形被裁掉；预览放大只让标记更方便，不能恢复遮罩外像素。运行新的 `--interactive` 时应重新框住完整人物，或使用 F/B 笔划初始化。交互窗口坐标经过模拟检查，但实际鼠标操作还需用户体验确认。

## 2026-10-07：多尺度特征与漫画重绘

v0.7 已成为默认 `comic` 路线；`--pipeline structure` 保留 v0.6，`--pipeline baseline` 保留第一版。原命令可继续运行，新的输出默认放大 4 倍，交互标记与特征分析仍使用原图尺寸。无新增依赖，不使用训练集或预训练权重。

函数入口 `cartoonize` 返回完整的具名中间结果：三尺度 RGB 方向响应、DoG、Lab 色度变化和邻域方向，分别进入线条、区域与明暗处理。候选线经细化、连通筛选、骨架图追踪与有限偏移的折线平滑，再赋予线宽、独立墨色和开放端收尖；区域由当前照片的确定性颜色原型和空间连通关系生成，小区域按邻接亲和度与色差合并。区域内部再次估计基础明度，平坦区域不强制生成阴影；底色与阴影色分别保存。

绘制使用区域多边形和笔画路径；透明轮廓以距离场覆盖率抗锯齿。笔画在线性 RGB 合成，额外超采样时对预乘颜色与 alpha 同步下采样，避免透明边缘产生暗色晕圈。原图和既有结果没有覆盖。

### 图片观察与限制

当前自拍的镜框和嘴缝比 v0.6 清楚，颜色由连续照片明暗变成明确的色块。线稿、纯底色和阴影形状能够单独比较；实际效果没有采用之前的手工示意图，也没有用预训练模型重新生成五官。

脸部仍会按光照形成较硬的区域边界，发际线有短碎笔画，部分眼睑较弱。区域编号是颜色与连通性结果，不代表已识别皮肤、头发、眼睛。暗线角色仅按响应来源区分；Hessian、流场线描、自动五官语义和更精细的阴影分组尚未实现。头像顶部与颈部仍受旧矩形遮罩裁切，外轮廓笔画会如实描出该裁切范围；下一次实际使用应重新确认人物遮罩。

保护／删除线条支持原尺寸二值 PNG，但没有新增独立的五官提示窗口。输出覆盖率只改善采样边缘，不估计半透明发丝，也不会恢复小图里不存在的细节。2400 万像素的内部画布上限在计算前检查；大图仍可能耗费较多内存，建议降低绘制和超采样倍率。
