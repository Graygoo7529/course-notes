# 安装依赖与下载模型

以下命令在 PowerShell 执行。先使用现有 CPU PyTorch，CUDA 留到有实际性能需求时再处理。

## 1. 环境与依赖

```powershell
Set-Location 'B:\LearnSpace\Course Notes\projects\cnn_face_cartoon'
conda activate d2l

python -m pip install -r requirements.txt -r requirements-face.txt
python -m pip check
python scripts/check_env.py --strict
```

环境检查中 `torchvision`、`timm`、`cv2`、`mediapipe` 应显示 `ok`。`--strict` 的失败退出码仅针对核心包；MediaPipe 的状态仍需查看。此次联合依赖解析计划保留已有 torch；实际安装后再通过导入检查确认兼容。

如 pip 需要代理，用这一条代替上面的安装命令：

```powershell
python -m pip install --proxy http://127.0.0.1:7897 -r requirements.txt -r requirements-face.txt
```

## 2. 下载全部模型

确保本机代理在 7897 端口运行。使用此前已允许的关闭 SSL 校验设置：

```powershell
python scripts/download_models.py --proxy http://127.0.0.1:7897 --insecure
python scripts/download_models.py --check
```

`--insecure` 仅关闭这个下载进程的证书校验，不改系统设置；证书正常时可去掉。可以直连时直接使用 `python scripts/download_models.py`，它遵循当前进程的代理环境。

脚本读取 `models.json`，先查询 Hugging Face 实际 revision，再按这个版本下载 `model.safetensors`、`config.json` 和 `README.md`。四个 CNN 不重复下载 `.bin` 格式权重；人脸关键点模型使用 MediaPipe 官方版本 1 的 task 文件。每个模型保存文件 SHA256 清单；CNN 大权重同时与 Hub 提供的 LFS SHA256 比较。

```text
model/
  resnet50/             ResNet50
  senet/                SE-ResNet50
  efficientnetv2/       EfficientNetV2-S
  mobilenetv3/          MobileNetV3-Large
  face_landmarker.task MediaPipe 人脸关键点模型
  face_landmarker.json  下载来源与文件校验值
```

下载中断后重跑相同命令即可，已完成且校验通过的文件会复用；未完成的单个文件重新下载。`--check` 仅验证本地文件完整性，不加载模型，不代表四种 CNN 已经通过推理检查。

只先下载 ResNet50 和关键点模型：

```powershell
python scripts/download_models.py --models resnet50 face --proxy http://127.0.0.1:7897 --insecure
python scripts/download_models.py --models resnet50 face --check
```

只查询下载计划，不下载权重、不修改模型清单：

```powershell
python scripts/download_models.py --plan --proxy http://127.0.0.1:7897 --insecure
```

模型来源见 [模型清单](../README.md) 和 [MediaPipe 官方模型说明](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker)。
